# Werkwijze: wat veilig stellen, en hoe

Vaste afspraak zodat ik nooit werk verlies. De regel achter alles: heeft het waarde over tijd, dan hoort het als bestand in dit brein en moet het gepusht worden. Leeft het alleen in een chat, een Project of een sessie, dan is het vluchtig en verdwijnt het.

## Staat veilig (in git, na push)

Alles in deze repo: standaarden, kennis, beslissingen, en de rest. Zodra het gecommit en gepusht is, staat het op GitHub met volledige historie. Raakt mijn pc kapot, dan clone ik het terug.

## Is vluchtig (verdwijnt als ik niets doe)

- Inhoud van een Claude Project (project-instructies en geuploade kennis). Leeft in Claude, niet in mijn git. De bronbestanden horen ook hier in het brein.
- Memory en chatgeschiedenis. Zit in Claude, niet in mijn git.
- Output die Claude Code of Cowork in een sessie maakt maar niet wegschrijft naar deze map. Weg bij het sluiten van de sessie.

## Bron van waarheid

Dit brein is de canonieke versie. Skills die ook in Claude Code of projecten draaien: de echte versie staat hier, daarvandaan kopieer ik naar waar ik ze nodig heb. Zo raken kopieen niet uit sync.

## Routine na elke sessie

1. Heeft de sessie iets opgeleverd dat waarde houdt? Schrijf het weg naar de juiste map in dit brein.
2. Committen in GitHub Desktop met een korte omschrijving.
3. Push origin.

Alleen wat gepusht is, staat veilig. Niet gepusht betekent: weg als de schijf sneuvelt.
