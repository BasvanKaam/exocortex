# AVD Security Guidelines cheat sheet: a 35-item starting point

In April 2023 Bas published v1.0 of an Azure Virtual Desktop Security Guidelines cheat sheet: a checklist of 35 of the most important and common security measures for locking down an AVD / Azure estate, usable with or without Nerdio.

Structure and caveats:
- The 35 measures are split into distinct categories.
- Some are additional paid-for services outside Nerdio, and some may already be part of a Microsoft subscription the reader owns. The sheet links to an overview of all Microsoft 365 licenses and what each includes (credited to Aaron Dinnage).
- It is explicitly framed as a starting point, not an exhaustive list of every security feature available, but should get you quite far.
- Main focus is AVD and related services. Distributed as a PDF download, and positioned as a living, work-in-progress document open to community feedback.

*Bron: blogpost 'The Azure Virtual Desktop Security Guidelines Cheat Sheet - v1.0' (2023-04-11), basvankaam.com.*
