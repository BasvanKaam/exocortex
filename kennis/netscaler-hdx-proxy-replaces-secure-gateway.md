# NetScaler HDX Proxy announced to replace the Secure Gateway (Synergy 2016)

How it worked then: announced at Citrix Synergy in May 2016, the NetScaler HDX Proxy was positioned to replace the well-known and widely-used NetScaler Secure Gateway, supporting up to 500 users in total. Relevant for small/cheap deployments where a single NetScaler is enough for secure remote access.
