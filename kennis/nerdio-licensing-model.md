# Nerdio consumption-based licensing model

How Nerdio Manager (Enterprise and MSP) is licensed and billed, as Bas explains it to prospects:

- **Deployed and invoiced through the Azure Marketplace**, so it is available in all Azure regions and the procurement process (especially in mid-to-large companies) is simplified. Install takes roughly 20-30 minutes.
- **Consumption-based, monthly active users** — you are billed only for users who actually used AVD through Nerdio that month, even if more are assigned. If usage drops (e.g. holiday season) the invoice drops with it.
- **Invoiced in arrears** — usage in one month is billed around the first of the next ('you pay Microsoft, Microsoft pays Nerdio', fully automated, tied to your Azure subscription/statement).
- **No upfront investment, no annual contracts, no vendor lock-in** — start or stop any day of the month; being 100% cloud-native there is nothing to unwind.
- **Support and all future versions included** in the license; releases ship roughly monthly.
- **30-day free trial** with no feature limits, support included.
- Usage/consumption data is viewable and exportable as a report directly from the Nerdio Manager UI.

This is Bas's go-to answer to the 'quanta costa?' question that every prospect asks at the end of a demo.
