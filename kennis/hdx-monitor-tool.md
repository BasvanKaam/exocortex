# HDX Monitor: HDX diagnostics tool

HDX Monitor provides detailed diagnostics on all current HDX technologies. Version 3.x supports XenDesktop 7.x and XenApp 6.5. HDX Monitor is also built into Director. Reference: CTX135817.
