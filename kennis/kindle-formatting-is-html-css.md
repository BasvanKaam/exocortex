# Kindle e-books are reflowable and effectively HTML/CSS under the hood

How it worked then (2016): a sellable Kindle book is not a simple Word-to-Kindle conversion. Most Kindle books are "reflowable" so the reader can change font size and type on the fly, which means the formatting really sits on HTML and CSS skills. Tables, font types and sizes, hard enters and whitespace, images, the table of contents and bulleted lists all need a special approach. Amazon KDP offers an online conversion of a Word or PDF upload, but in Bas's experience the output was far from satisfying. Tables had to be rewritten into bulleted text lists, and even then layout could break on older devices (the Kindle DX showed off bulleted lists). Lesson: read the Amazon Kindle Publishing Guideline before publishing, and budget real time for it.
