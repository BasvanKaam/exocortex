# Bas's caution on pre-configured Start menus and desktops

When choosing how to deliver application shortcuts, Bas cautions to think carefully about which solution fits. Not all users will be happy with a pre-configured Start menu or desktop, especially when dozens or more applications are involved. There will always be pros and cons no matter which route you choose. He stresses the flexibility available (Start menu, desktop, let users decide, or a combination) but frames the decision as a deliberate trade-off, not a default.
