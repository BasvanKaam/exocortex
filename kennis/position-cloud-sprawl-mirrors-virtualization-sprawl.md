# Cloud will repeat the virtualization sprawl mistake unless governed

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The framework's stance is that cloud's frictionless deployment is a trap that repeats the virtualization sprawl experience. Virtualization promised better hardware utilization but, because deploying became so easy, it caused an explosion of instances, a chaotic landscape, and an outdated configuration database; total cost did not come down. He expects readers to nod in recognition. The lesson: without deliberate governance, tagging discipline and automated control, the cloud will produce the same sprawl and the same loss of cost and risk control. Ease of deployment is precisely why stricter governance is needed, not less.
