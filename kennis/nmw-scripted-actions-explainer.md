# What Nerdio Scripted Actions are

Scripted Actions in Nerdio Manager for WVD: reusable automation scripts you run against your environment.

- Ships with predefined scripts that are easy to change and clone, plus the option to upload your own and build out a personal library.
- Can run code outside the virtual machines, directly in Azure, to deploy and build different Azure resource types. This is done via Azure Automation Runbooks and can leverage both the AzureRM and Az PowerShell modules.
- PowerShell scripts can be combined with tools like Chocolatey and the Evergreen PowerShell module (e.g. for application install/update automation).

His reusable framing: Scripted Actions turn NMW into more than a management console; they are a building-block layer for automation and integration.
