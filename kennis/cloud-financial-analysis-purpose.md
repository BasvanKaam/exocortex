# Purpose of the cloud financial analysis (business case)

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The financial analysis (a.k.a. the business case) answers a deceptively simple question: what does an application in my data center cost, and what are the financial consequences of going to the cloud? Any organization with a cloud strategy should be able to answer it.

Its purpose is to give insight into the financial consequences of the various cloud movements: what happens when I pick up this application and bring it to the cloud. The goal is to select the optimum landing site per application, and that decision requires the business case alongside it, which in turn requires insight into the current cost per application.

This insight requires a financial model that can produce multiple 'views' or cross-sections of the costs: all costs for one application, or all costs for one type of platform (e.g. what it costs to maintain the Linux servers in our own data center). How deep you dig depends on the application: more detailed, reliable input lets you investigate scenarios more granularly. Connecting a multitude of information sources requires translation, interpretation and making (validated) assumptions.

Data sources include the data center's investments, maintenance costs and net delivered capacity; an application's infrastructure footprint (servers, storage, memory, licenses); and developer hours per application. Standard units (e.g. average capacity of a server) and benchmark data for comparable organizations can supplement missing data, so you rarely need to count every disk or poll every employee.
