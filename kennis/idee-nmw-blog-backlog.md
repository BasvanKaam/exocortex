# Idea: NMW Blog/Content Backlog

Bas's running list of content angles for Windows Virtual Desktop / Nerdio Manager. Reusable as a content-planning seed bank, the angles map to recurring buyer questions.

## Angles
- How to start with WVD as cheaply as possible, then bridge into image management and autoscaling (e.g. auto install + config of FSLogix).
- Costs and autoscaling: "how do we do that, very simply" framed as the hot topic.
- Image management and lifecycle: contrast the hard way (Azure Image Builder, Azure DevOps, JSON, PowerShell, specialist knowledge that can walk out the door when a person leaves) with the NMW way where that problem disappears.
- Migrating from old to new.
- Monitoring with Sepago.
- Use a Forrester cost piece as a reference model.

## Repurposing tactic
- Translate existing Nerdio blogs into Dutch.
- Partially rewrite existing blogs and republish on basvankaam.com (own channel) so the work does double duty.
