# Azure cost management and optimisation tools

Reference list of Microsoft Azure cost-management and optimisation tooling cited by Bas.

**Analysis & monitoring**: Azure Cost Management + Billing (spend per resource/group/subscription); Azure Advisor (recommendations to cut unnecessary cost); Azure Monitor; Azure Log Analytics; Azure Pricing Calculator (estimate costs up front).

**Reduction & optimisation**: tagging strategy (e.g. Environment=Production, Department=Finance); Resource Groups & Subscriptions to separate workloads; Azure Reservations (save up to 72% by reserving capacity for VMs, storage or databases); auto-shutdown policies and scaling plans; Spot Virtual Machines (cheap, short-lived compute for non-critical workloads); Azure Hybrid Benefit (use existing on-prem Windows Server and SQL Server licenses to lower Azure cost).

**Budgeting & alerts**: Azure Budgets; Azure Policy (e.g. block expensive VM types); Azure Savings Plans (flexible pricing for long-term compute use); Azure DevTest Labs (auto-pause/delete dev/test VMs).
