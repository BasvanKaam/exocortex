# Microsoft Azure Profile and Strengths

Microsoft Azure holds ~23% global market share, a strong second. Its growth comes from Microsoft's marketing power and seamless integration with existing Microsoft products, making it the logical choice for organisations already in the Microsoft ecosystem.

Key strengths:
- Unmatched integration with Active Directory, Office/Microsoft 365, Windows operating systems, Azure Virtual Desktop, and Cloud PC. An IT department can keep using Active Directory for identity while staff get a flexible, secure workplace via Azure Virtual Desktop.
- Strong focus on hybrid cloud via Azure Arc and Azure Local, letting companies combine on-premises infrastructure (nearly) seamlessly with cloud services. Ideal for sectors with high data/compliance priorities such as healthcare and financial services.
- Proven enterprise solutions with a wide datacenter and points-of-presence network for low latency and high availability.
- Innovation in AI (Bas notes 'OpenAI gekocht'), machine learning, and IoT, e.g. Azure Cognitive Services and Azure IoT Hub.
