# Worked example: bank treats core-banking software as commodity

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

A worked illustration of the commodity-vs-competitive strategy: a traditional bank launching a new brand for a specific product/market combination needs core-banking functionality (debit/credit accounts, deposits, payment cards).

Applying the strategy, the bank concludes that core-banking software is a commodity that by itself provides no competitive advantage. The competitive edge comes from how they parameterize and configure the software (for example the interest rates). So the bank procures core-banking functionality as-a-service from a SaaS provider and instead focuses all attention and resources on the end-user-facing self-service portals and mobile apps. It is the end-user functionality that ultimately determines the new product/market combination's success.
