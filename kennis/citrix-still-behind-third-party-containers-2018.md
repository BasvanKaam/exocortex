# Citrix's native options still lag third-party containers (May 2018)

Bas's stance after Synergy 2018: the WEM/UPM announcement is good and welcome, but if you want the full picture today (full profile support, caching for OneDrive/S4B, Outlook search index roaming, across both VDI and session-based) using only Citrix products, 'you're out of luck, at least for now.' A third-party product is still needed. He frames this neutrally rather than as criticism ('Not a bad thing, just something to be aware of').

He also flags an interesting overlap: Microsoft announced Per-User Windows Desktop Search catalogs as part of Server 2019 (not limited to Outlook, session-based and VDI), and notes it took Citrix almost a year to build their narrower equivalent. His tempered read: Server 2019 is still far from production-ready and migrations from 2012/2016 will take months or years, so don't expect the Microsoft path to land soon. He's deliberately even-handed, declining to judge UPD since he has no hands-on experience with it.
