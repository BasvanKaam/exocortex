# Idea: Community Scripted Actions Hackathon

A community contest built around Scripted Actions: solve day-to-day challenges in setting up, managing, and cost-optimizing AVD/Azure environments, then publish the results publicly. The mechanics, reusable for any community build-event:

- **One week, fixed window.** Kick off with a recorded launch event a few days before, then run for a full week including the weekend. Hard submission deadline at a set time/timezone.
- **Ownership stays with the creator.** The organizer never becomes owner, never resells or reuses entries except as stated. Everyone is credited at the top of their script so authorship is visible.
- **Everything ships publicly.** All entries go to a public GitHub repo, free to download and use. The point is shared optimizations, not lock-in. A subset can also flow into the product's Scripted Actions library for customers.
- **Open to anyone.** "You do not have to be a master scripter, at all." Reusing your own existing code is fine; it does not have to be brand new.
- **Two categories:** Challenges/problem-solving and Freestyle, judged equally (no bonus for picking a challenge over your own idea).
- **Scoring rubric:** usability, originality, functionality, and error/fault-free, max 3 points each. A panel of named community/MS experts reviews; if a change is needed the author is asked to agree first.
- **Anything PowerShell-launchable qualifies:** Bicep, ARM, JSON, Azure Runbooks, work outside the VM, etc.
- **Topic seeds for inspiration:** performance and cost optimization, image/app management, integrations, AVD/Azure component deployment, monitoring and alerting, MSIX app attach, security hardening, troubleshooting.
- **Amplify the participants.** Encourage entrants to share on their own channels under a dedicated hashtag, and amplify everything they post.

Related idea in the same effort: **'100 days of Scripted Actions'** as an ongoing content series, and sharing all Scripted Actions publicly via GitHub rather than only inside the product.
