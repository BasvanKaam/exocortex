# Ten-Category Security Portfolio for Zero Trust

Bas provides a (deliberately non-exhaustive) list of products, technologies and services across ten layers/rows that you could deploy to implement Zero Trust. He notes some entries are perhaps a bit 'vergezocht' (far-fetched) and rarely seen in practice yet, but expects that to change quickly. The ten categories:

1. Security policy, rules, responsibilities, compliancy (GRC software, compliancy tools, frameworks like ISO 27001/NIST CSF/GDPR, policy automation, quantum-resistant cryptography, digital twins for policy simulation).
2. User awareness, training, support (security awareness training, phishing simulations, e-learning, gamified platforms, AI-driven behavioural training).
3. Endpoint encryption, patching, updates, antivirus, anti-malware (EDR, AV, patch management, disk encryption, MDM, AI-driven patch management).
4. Authentication, authorization, identity management, 2FA (IAM, MFA, PAM, Zero Trust solutions, AI behavioural authentication, behavioural biometrics).
5. Email security, filtering and encryption (secure email gateways, email encryption, spam/phishing protection, AI detection, ML-based DLP).
6. Network, DMZ, firewall, data loss, proxy (NGFW, IDS/IPS, WAF, ZTNA, AI network monitoring, autonomous network response).
7. Data classification and system categorization (classification tools, DLP, auto data tagging, AI-driven classification).
8. Disaster recovery, back-ups, business continuity, processes (backup solutions, DRaaS, BCM, AI-based recovery).
9. Server encryption, hardening, patching, updates, antivirus, anti-malware (server AV, hardening guides like CIS Benchmarks, server encryption, AI server protection, autonomous bug detection).
10. Monitoring, alerting, responding, reporting, audits (SIEM, SOC services, threat intelligence feeds, AI threat detection, Autonomous Cyber Reasoning Systems).

Example vendors named include RSA Archer, ServiceNow, OneTrust, KnowBe4, CrowdStrike Falcon, Microsoft Defender, Intune, Okta, Azure AD, CyberArk, Proofpoint, Mimecast, Palo Alto, Fortinet, Zscaler, Cloudflare, Darktrace Antigena, Varonis, Veeam, Acronis, Zerto, Rubrik, CIS Benchmarks, Pentera, Mayhem (ForAllSecure), Microsoft Sentinel, IBM QRadar, Vectra AI.
