# Generic security awareness fails; training must be role-based

Bas argues that the end user is consistently the weakest link in security, and that generic, one-size security awareness training does not move the needle. His stance: security training must be job-specific. An IT admin, a finance employee, HR, and sales each face different access patterns, different threats, and different responsibilities, so each should get its own micro-training built around how and why secure access matters in their daily work. Phishing and social engineering keep working precisely because awareness stays generic. Tooling (e.g. NME insights and compliance reporting) supports this, but the behavioural shift is the point.
