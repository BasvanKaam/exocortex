# A Cloud Strategy sets a target AND a roadmap for the installed base

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

A Cloud Strategy must do two things: set the target for future application workloads, and provide a roadmap for how to deal with existing applications and data centers. Because most organizations have a large installed base in the data center, the central question is how to deal with the remainder of applications.

The roadmap should give insight into what needs to be done across four dimensions:

- Organizational capabilities
- Technical prerequisites
- Governance
- Workload migrations
