# Windows Virtual Desktop: multi-user Windows 10 as DaaS on Azure

How WVD was framed at announcement (Ignite 2018, launch expected first half of 2019): a full multi-user Windows 10 experience virtualized in the cloud, always up to date, available on any device, exclusive to Microsoft Azure, deployable in minutes with unified management in the Azure Portal. Bas's caveat is the durable lesson: spinning up VMs is the easy part. A multi-user Windows desktop consumed as 100% DaaS still leaves 'loose ends', user data, profiles, application delivery, UX monitoring, that the platform itself does not fully solve. Microsoft acquired FSLogix around this time to help with profile/container handling.
