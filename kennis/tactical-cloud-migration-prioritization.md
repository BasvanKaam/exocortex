# Tactical Cloud Migration Prioritization

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Once the strategic drivers are identified, you map every potential cloud migration to them. The migration paths considered are repurchase, refactor, replatform, and relocate.

Classification rule:

- A migration (or development) that addresses one or more strategic drivers is a Tactical Cloud Migration.
- Tactical migrations should be prioritized over migrations with lower impact.
- Migrations that tick none of the boxes are not tactical, but may still be required for reasons such as closing a data center or transferring an outsourcing contract to a new supplier.

This turns the strategic drivers into a concrete prioritization filter for the migration backlog.
