# Idea: Nerdio Scripted Actions Hackathon

A community scripting contest I designed and ran (first edition 2021, 300+ signups). The core idea is reusable as a program template, not just a one-off event.

## The concept
Get the WVD/Azure admin community to write PowerShell scripted actions that solve real day-to-day pain (setup, management, cost optimization) and make ALL of them publicly available for free, with or without Nerdio installed. The contest is the engine; the public library is the payoff for the whole community.

## Design principles that make it work
- **Vendor-neutral on purpose.** Scripts do not have to be Nerdio-specific. They should run on native Azure too (host pools, images, MSIX App Attach, Azure Files, FSLogix, any OS/VM). This widens participation and makes the output useful to everyone, which in turn builds goodwill toward Nerdio.
- **Two levels, judged separately.** Beginner and Advanced, with their own prizes and rankings. You pick one level; you cannot enter both. This keeps newcomers from being crushed by experts and lowers the barrier to entry.
- **Two categories: Challenges and Freestyle.** Challenges are a curated list of concrete problems; Freestyle is anything you think makes a WVD/Azure admin's life easier on time or cost. Both weighted equally, so original ideas score as well as solved challenges.
- **Author keeps ownership.** Scripts stay with their creator; Nerdio does not become the owner. Some scripts may later be added to the Nerdio Manager scripted-actions library, but only with the author's explicit permission.
- **Low barrier, high amplification.** Anyone can join, no master-scripter requirement; swag for the first signups; encourage participants to share on social (a campaign hashtag) and amplify them in return.

## Logistics pattern
- Runs two full weeks including weekends; kicked off with a recorded launch event.
- Submit via the public GitHub repo, your own public repo (send the link), or email.
- Each submission needs a clear header describing which challenge it solves (or the Freestyle idea) and proof it ran (short video, screenshot, or code output).
