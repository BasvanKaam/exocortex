# salomon-it.blog: A Dedicated Blog Platform Plan

A short pitch deck (slides) for standing up a dedicated company blog at **www.salomon-it.blog**, separate from the main site. Note: the file is named "Salomon RaaS" in the corpus but its content is about the blog, not Roadmap-as-a-Service.

**Why** (limitations of the current platform): more control / things in own hands / faster, a more professional look, simple and efficient.

**How**
- WordPress.com basic subscription.
- Agreements around content, placement, editing, etc.
- Multiple authors by invitation.
- Domain: www.salomon-it.blog.

**Rollout ("wat verder nog")**
- Blog reachable from salomon-it.nl and prominently visible on visiting the .nl site.
- Invite colleagues to follow the blog by email.
- Invite authors and brief them.
- Add Google Analytics.

The through-line is Bas's recurring instinct to build a content/authority channel and run it deliberately (invited authors, editorial agreements, analytics, cross-linking from the main site).
