# Serializing a finished book onto WordPress is more work than it looks

Having 28 chapters finished in Word and Kindle format did not make putting them online quick. As experienced then (2019): WordPress mangles the format and layout, which has to be fixed manually per chapter. TIFF images used for the paperback are not supported by WordPress, so almost all had to be converted to PNG using Snagit. Each image then needs uploading, sizing and correct placement; text copied from Word needs re-carving into smaller paragraphs; sponsor logos, links that open in a new window, and chapter-to-chapter navigation buttons all have to be wired up by hand. Individually trivial, but together a real time sink to keep look and feel consistent.

How it worked then: a useful reminder that converting an existing long-form deliverable into a web series is a layout/asset project, not just a copy-paste.
