# Why RDS Easy Print falls short for cloud/remote printing

Microsoft's standard RDS printing solution, Easy Print, works OK for smaller on-premises environments but misses important capabilities for cloud/remote-based environments: network printer support, traffic compression and encryption. Being a "universal" solution also means more advanced printing features aren't available. This gap is what third-party printing vendors (e.g. Tricerat) addressed for WVD. How it worked then (2019): Easy Print was the built-in baseline and its limits drove the need for add-on printing stacks in DaaS/VDI.
