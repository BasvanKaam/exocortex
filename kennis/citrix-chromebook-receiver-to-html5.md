# Citrix dropped the Chromebook Receiver for HTML5

How it worked then (late 2013/2014): Citrix removed the native Receiver for Chromebook from the Chrome Web Store and replaced it with the StoreFront 2.x integrated HTML5-based Receiver. The native Chrome Receiver had a poor reputation in forums and blogs for not working as it should. The practical consequence: getting Citrix to work on a Chromebook now depended on running a recent StoreFront release; on older StoreFront it was "pretty much useless".
