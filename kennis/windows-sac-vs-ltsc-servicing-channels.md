# Windows SAC vs LTSC servicing channels

**SAC (Semi Annual Channel)** applies to Windows 10 and Office 365/ProPlus. A new Windows 10 version ships every 6 months; ProPlus can receive new features monthly. Channel choices for 365/ProPlus: Monthly Channel (features monthly), Semi Annual Channel (features twice a year, January and July), and Semi Annual Channel Targeted (pilot users test upcoming features before the regular SAC). Windows 10 has a similar Targeted option.

**LTSC (Long Term Servicing Channel)** can apply to Windows 10 and Server 2019. It is meant for machines with a special, fixed role: kiosk PCs, medical equipment, payment systems. These must stay as stable and secure as possible and are not served by the latest features; quality/security updates are still delivered immediately. New LTSC editions normally appear every 2 to 3 years.

Servicing tools exist to let organizations defer/stage update rollouts within both SAC and LTSC. Note: SAC versions also apply to the upcoming Windows 10 multi-session variant in the Windows Virtual Desktop.

Dated: specific to the 2019 Windows 10 / Server 2019 servicing model and the SAC twice-a-year cadence, both since superseded.
