# GPUs in VDI: a tool in the toolbox, not a default

GPU adoption in VDI/SBC was slow because GPUs were (too) expensive and a properly designed environment performs fine without one. A GPU boosts overall UX but adds another layer to set up and manage. Treat it as 'a tool in the toolbox': use it where it makes sense, not in every design. Durable design principle for sizing virtual desktops.
