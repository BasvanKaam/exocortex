# How Bas teaches the five essential cloud characteristics

The backbone of Bas's intro-to-cloud talk is the five essential NIST cloud characteristics, each made concrete:

1. On-demand self-service — storage, network, compute, applications, hypervisor, scaling and images all provisioned without manual hand-offs.
2. Broad network access — reachable from phone, tablet and PC/laptop.
3. Resource pooling — memory pool, storage pool and CPU pool shared across tenants.
4. Rapid elasticity — flexibility through autoscaling: a base capacity (minimum active), then action triggered either by utilization (e.g. when 80% of CPU or memory is in use) or on pre-set times and days.
5. Measured service — monitored, controlled and reported.

Delivery models he contrasts on the same slides: VDI (desktop), RDSH (server) and DaaS (desktop and server), each shown both on-prem and in cloud. DaaS is positioned as cloud-based VDI/RDSH (Windows 10 multi-session, Windows 7, Server 2012/2016/2019) reachable from any device.

This is Bas's reusable structure for explaining cloud from first principles to a mixed business/IT audience.
