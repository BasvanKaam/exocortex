# Nerdio Manager Is an Orchestration Layer, Not a Security Product

Bas is explicit and repeats it: Nerdio Manager for Enterprise is an orchestration and management layer, not a security tool. In a Zero Trust design it is the thing you configure to enforce principles, but it is not itself the security boundary. This shapes how he teaches the shared responsibility model (Microsoft / Nerdio / customer) and the control-plane vs workload-plane split: learners must know where Nerdio operates and where their own responsibility begins.

A second stance: traditional perimeter-based security no longer applies to modern EUC and DaaS. Because identity, remote access, automation, and cloud scale fundamentally change the attack surface, security has to be designed in Zero Trust terms from the start, not bolted on as a perimeter.
