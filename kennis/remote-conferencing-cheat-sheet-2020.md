# Remote video-conferencing cheat sheet (v1.0, 2020)

A single-sheet comparison of five remote meeting/video platforms, built at the start of the 2020 remote-work surge. Compared dimensions include: deployment (on-prem/cloud/mobile and OS support), billing terms (monthly vs annual), VDI/platform support (Citrix, VMware, RDSH, Windows Virtual Desktop), add-ons, max users visible in video vs total in meeting, HD video, raise-hand, background-noise reduction, file/screen sharing, recording, cloud storage, whiteboard, free tier, price band, REST API and support options.

Notable point-in-time facts captured: Microsoft Teams could optionally run online events up to 10,000 attendees but in early 2020 still lacked a raise-hand option and background-noise reduction (both flagged as 'comes later in 2020'); Teams was the only listed option with FastTrack deployment support and was bundled in the Office 365 license. Webex Meetings Web App for Citrix Virtual Desktop environments was in beta. Background-noise reduction varied: some had it native ('ambient noise filtering', 'auto reduction'), one only via a third-party tool such as Krisp (a cross-platform Windows/Mac noise-reduction add-on that works with any solution). Price bands ran roughly €4.20 to €34.40 per user/month across the field.
