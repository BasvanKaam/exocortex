# Comparing a Physical Server to Cloud Isn't Fair

A Bas opinion / framing he flags explicitly: it is NOT a fair comparison to say that buying a physical server costs you less than running an equivalent system virtually in Azure over, say, three years. There's more to it than that (which the chapter unpacks via TCO).

His summary of the trade-off: the choice between Capex and Opex depends heavily on the company's needs and strategy — Capex offers long-term value with your own infrastructure, while Opex offers flexibility without high initial costs.

## Bron-citaten (NL, verbatim)

> Het is geen eerlijke vergelijking om te zeggen dat als ik een fysieke server aanschaf dat mij minder kost dan dat ik een dergelijk systeem virtueel in Azure afneem over een periode van bijvoorbeeld drie jaar.
