# Curated cloud self-study resources (Masterclass handout)

The resource list Bas hands learners so they keep learning after the Masterclass. Specific to how he teaches: he wants people plugged into the cloud conversation continuously, not just during the course.

- Podcasts / channels: The Cloudcast, GCP/AWS/Azure podcasts, Cloud Engineering Daily, Cloud Unfiltered; vendor YouTube channels (Microsoft Mechanics, AWS, Google Cloud); AWS/Azure/GCS "this week/month" series.
- Customer/startup stories from each hyperscaler as proof-point material.
- Stay-current habit he recommends: set a Google Alert on your own relevant keywords (he shares his own as an example).
- Events (all run a Dutch edition): Microsoft Ignite on Tour, AWS Summit, Google Cloud Summit; community groups DuCUG (Citrix), VMUG (vExpert).
- Entry-level certifications he points to: Azure Fundamentals (AZ-900), Microsoft 365 Fundamentals (MS-900), AWS Cloud Practitioner (CLF-C01), each with free official training.
- Inspirational reading he assigns: The Phoenix Project, Cloudonomics, Cloud Computing: Concepts/Technology/Architecture, Transitioning the Enterprise to the Cloud, Chaos Engineering, The First 90 Days, plus presentation craft (Slide:ology, Presentation Zen, How to talk like TED).
