# Citrix Workspace Cloud credential and authentication handling

How it worked circa 2015-2016. CWC's security model for keeping customer credentials out of the cloud:

- **Admin auth:** admins sign in via the Citrix online sign-on system; a one-time signed JSON Web Token is generated granting access to the Apps and Desktops service.
- **User credentials:** encrypted by the Cloud Connector using AES-256 plus a random one-time key generated per launch. That key is forwarded to Citrix Receiver (it never enters the cloud) and passed to the VDA, which uses it to decrypt the user password at session launch, giving a single sign-on experience.
- **MCS / AD:** the Cloud Connector's machine account has only read permissions in Active Directory, so when MCS creates machine accounts the admin is prompted to approve each operation.
- **Hypervisor passwords:** generated by the admin, encrypted, and stored in the cloud-based SQL database.
