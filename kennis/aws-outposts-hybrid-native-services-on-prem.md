# AWS Outposts: native AWS services in your own datacenter

How it was announced at re:Invent 2018: AWS Outposts brings native AWS services, infrastructure, and operating models to virtually any datacenter, co-location space, or on-premises facility, using the same APIs, tools, and hardware across on-prem and cloud. Customers could choose between VMware Cloud on AWS Outposts or the AWS-native variant. It was positioned by many as one of re:Invent 2018's biggest announcements, with GA scheduled for Q4 2019. Bas read it as a major hybrid-cloud signal: the biggest cloud player formally acknowledging a hybrid world, fitting a trend of AWS cloud services (RDS, Snowball Edge compute/GPU) coming to on-prem use.
