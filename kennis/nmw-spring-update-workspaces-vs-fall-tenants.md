# WVD Spring (ARM) release: Workspaces vs Fall Tenants in NMW

How it worked then (mid-2020): the WVD Spring update was officially named 'The WVD ARM release.' It introduced Workspaces as the top-level object, replacing/sitting alongside the older Fall release Tenants concept. Bas highlights that Nerdio Manager for WVD could manage both Workspaces (Spring) and Tenants (Fall) 'from within the same GUI' during the transition. Dated detail useful as a marker of the Spring-to-Fall WVD object-model shift and how tooling bridged it.

*Bron: blogpost 'Speaking at IGEL Disrupt 2020 - Nerdio Manager for WVD' (2020-06-17), basvankaam.com.*
