# Key Takeaways Ch.15: the modern IT professional

Bas's chapter-15 takeaways on how the IT role is changing:

- The IT world changes fast, and so does the role of IT professionals. Where it used to revolve around technical specialisation, the cloud demands a broader focus: a modern IT professional combines technical skills with insight into business goals and strategy, collaboration and communication.
- The cloud opens the door to AI, machine learning and virtual reality, making it easier to analyse data, recognise patterns and create interactive experiences.
- Security stays a key concern as ever more data sits in cloud environments; providers keep investing in protective technology.
- SaaS use (e.g. Microsoft 365) grows, and more companies see the advantages of hybrid and multi-cloud — but in practice actual adoption of these strategies still disappoints. The interest is there; the real-world application lags.
- The cloud affects sustainability: datacenters consume much energy and water for cooling, especially problematic where those resources are scarce, demanding more conscious choices.
- Innovation matters but must be combined with practical goals; a balanced approach prevents innovation harming stability and operations. Structures like an Innovation Board or an Office of the CTO can help.
- Tools like the hype cycle and Magic Quadrants give insight into new technologies and vendor positions.
- Personal development is necessary: keep learning, earn certifications, step out of the comfort zone. Read, learn and share — this strengthens both the professional and the organisation.
