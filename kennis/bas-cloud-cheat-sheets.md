# Bas's Cloud 'Cheat Sheets' mapping provider service names

Bas recounts that he previously built several 'Cheat Sheets' listing commonly used cloud services (and the providers' service names) from the three big providers, mapped to the normal datacenter service/product name you'd already recognise. These overviews proved very popular. But he quickly discovered it was an almost impossible task to keep them up to date. The example shown in the book dates from late 2019, and he asks the reader to imagine how different it would look today. He challenges the reader to compile a similar overview themselves.
