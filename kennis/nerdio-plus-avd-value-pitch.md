# Why Nerdio on top of AVD: the five-minute value pitch

My compressed argument for what Nerdio is about, delivered in five minutes:

- **Cost optimization** - Nerdio + AVD is cheaper than AVD alone. (The counterintuitive headline: adding a paid layer lowers total cost.)
- **Simplicity** - anyone with some EUC knowledge can do it.
- **Acceleration** - cheaper and simpler makes projects go faster.
- **Involvement** - Nerdio can be part of your project to make it a success.

Framing I lean on: Nerdio Manager *extends* the native AVD admin experience rather than replacing it. Deployment-wise it's a standalone Azure application deployed into the customer's own tenant - NOT an Azure Managed Application, so there's no third-party access - deployed and billed through the Azure Marketplace, available in all regions worldwide. That "your tenant, no third-party access" point is the one I always make to address the trust/security question up front.
