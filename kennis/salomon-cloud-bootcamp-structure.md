# Salomon Cloud Bootcamp: two-day course structure

Bas's own two-day, vendor-independent Cloud Bootcamp is built so the adoption framework runs as the red thread across both days, with the framework phases deliberately split across the agenda rather than taught in one block.

Day 1 agenda: "Er was eens..." (history) -> Cloud principles -> The Cloud anno 2020 -> The new business reality -> Framework: Strategy -> Cloud economics -> Architectures and services -> Summary.

Day 2 agenda: Framework: Insight -> Data and Governance -> Security -> Framework: Execution -> Exit strategy -> Community and practical tips -> Framework: Adoption -> Future and trends.

The framework appears at four points (Strategy on day 1; Insight, Execution, Adoption on day 2), interleaved with supporting topics so each phase lands next to the relevant business/technical context. Mix is deliberately business-plus-technology and fully cloud-independent. Delivery is whiteboard-led and interactive: discussion and peer learning are central, learners actively take notes.
