# M365 E3 already entitles you to AHU for WVD

Licenses that entitle the WVD service (incl. FSLogix) for Windows 10 Enterprise multi-session and single-session: Microsoft 365 E3, E5, A3, A5, F3, Business Premium, and Windows E3, E5, A3, A5.

A point often missed in 2020: with Microsoft 365 E3 you have effectively pre-paid (the concept behind Azure Hybrid Use Benefit, where you buy licenses upfront) for both Windows 10 Enterprise multi-session and single-session. So when you configure WVD in the Azure calculator, AHU already applies automatically.

Naming context: as of 21 April 2020 the Microsoft Office 365 SMB SKUs were renamed to Microsoft 365, which adds to the confusion.
