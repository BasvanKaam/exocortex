# Cloud Advice Must Be Vendor-Independent

Bas's stance: a cloud adoption framework should not be a clone of any provider and should not steer toward a particular vendor. The SCAF is positioned as 'no thirteen in a dozen', operating completely vendor- and brand-independent, with the technology made to follow the business objectives rather than the other way around. The differentiator he leans on is 'we do it differently / it can be done better'. This vendor-independence is a recurring core position across his cloud-era writing.

Source: Bas van Kaam, Salomon IT blog, 2019-08-28.

*Bron: blogpost 'Wat een Cloud exit strategie inhoudt? Het SCAF?' (2019-08-28), salomon-it.nl.*
