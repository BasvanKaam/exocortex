# AVD and Cloud PC go hand in hand, pick per use case

Bas's stance: Cloud PC is not a replacement for AVD, it is a complement. Both run on the same underlying Azure Virtual Desktop architecture, so most organizations will run a mix (his rough split: 70-30 in favor of AVD). The job is not to crown a winner but to pick the right desktop type per user and per use case, then keep a strong focus on ongoing manageability and the financial side. Simplicity (Cloud PC) comes at the cost of flexibility; AVD gives more control, more flexibility, no black box. Before getting too excited about a fixed-price cloud PC, read the prerequisites, networking and AD requirements, and limitations first.
