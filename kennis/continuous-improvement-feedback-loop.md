# Governance communication as the continuous-improvement loop

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The main objective of governance is to achieve company goals. The cloud governance communication process is important not only for conveying information but for collecting it: feedback from that process is used as input for continuous improvement.

In the Target Operating Model multiple activities and processes embed continuous improvement, such as maintaining Service Catalog integrity and resource utilization optimization. The test to apply is to keep asking whether what you do really contributes and is in line with how you want to do things, so you stay connected with the mission instead of just going through the motions.
