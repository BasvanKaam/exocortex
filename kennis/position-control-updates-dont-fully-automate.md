# Organizations want control over updates, not full automation

Bas's observed stance from the whitepaper: although Microsoft recommends letting devices update automatically (the default, via the Office CDN), in practice he rarely sees organizations do this. They want more control. He frames Update Channels and tooling (ODT, Group Policy) as the mechanism for that control: deliberately staging which user groups get which functionality when, with pilot and compatibility-tester groups on faster channels and the bulk of users on the slower default. The underlying philosophy: test before production, never push features to everyone at once.
