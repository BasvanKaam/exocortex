# Bas's distinction between authentication and verification

Bas is deliberate about the difference between two terms people often blur. Authentication is making sure somebody is who he or she claims to be. Verification (he also calls it validation) is finding out which resources are assigned — i.e. the permissions — to the user, which are then displayed in the user's store ready for subscription.

User authentication and resource enumeration go hand-in-hand. He flags this distinction explicitly so readers notice when he uses each term.

## Bron-citaten (NL, verbatim)

> Note how I mention user authentication and user validation. There is a distinct difference.
