# Use one UEM layer across physical, virtual, on-prem and cloud

Bas's recommendation (Jan 2019, in a Liquidware-sponsored framing): if you run a mix of physical, virtual, on-prem and cloud desktops, don't stitch together two or more tools to handle profiles, app delivery and monitoring, that wastes money and time. Pick one adaptive workspace-management stack that works everywhere so moving between clouds or between on-prem and cloud becomes optional and low-hassle. He points to Liquidware's stack (ProfileUnity UEM, FlexApp application layering, Stratusphere UX monitoring) as a fit because it harvests and reapplies existing profile/app/policy data, smoothing migration to Azure WVD. Note this is partner/sponsored content, so read the vendor preference accordingly; the underlying principle (single adaptive UEM layer over hybrid estates) is the durable point.
