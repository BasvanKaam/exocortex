# Opdracht 10: Exit Strategy (XYZ-Care)

Bas's tenth assignment frames a cloud exit strategy as an essential part of the broader IT strategy. XYZ-Care Health Group is considering Azure Virtual Desktop (AVD) and other cloud solutions; as a care organisation with strict AVG/GDPR norms and critical dependencies on the EPD, planning tool and financial management system, a clear exit strategy is indispensable.

The tasks:
- Identify cloud-exit risks: vendor lock-in, compliance (AVG) challenges, technical limits on exporting data.
- Analyse dependencies: per application, show how it connects to other systems/data, how data and functionality can be exported and moved, and which tools or APIs may be provider-specific.
- Define five concrete exit triggers (e.g. sharply risen costs, degraded performance, no longer meeting AVG norms) and motivate their relevance.
- Draft a high-level exit plan to an alternative hosting environment (on-prem or another provider), covering data migration, application portability, security measures, and a time and cost estimate.
- Analyse a provider's SLAs (e.g. Azure) and flag points needing extra attention in the exit plan: availability definitions, data retention after termination, compensation arrangements - and describe how XYZ-Care ensures these don't threaten business continuity.

He notes the exercise also pushes participants to present findings clearly and convincingly to management to build support.
