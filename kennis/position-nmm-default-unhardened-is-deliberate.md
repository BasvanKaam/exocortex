# NMM's Un-Hardened Default Is a Deliberate Flexibility Choice

Bas frames NMM not being pre-hardened by default as an intentional trade-off favoring flexibility and PoC speed, not an oversight. The default deployment prioritizes speed and functionality; security hardening is then layered on post-install to reduce attack surface and align with CIS/NIST/ISO 27001. His corollary stance: the goal of hardening guidance is to secure the environment without breaking functionality, so the supported, documented methods (access restrictions, service endpoints) matter more than maximal lockdown.
