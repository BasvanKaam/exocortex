# WCGF Domain: Financial Management and Cost Optimization

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

A Cloud Governance Framework operation domain covering how IT spend is controlled and optimized in the cloud. Its governance purpose is twofold: ensure proper use of the IT budget and maintain alignment between IT and the business.

Key moves in the domain:
- Adapt the purchasing/approval flow to the elastic nature of cloud while keeping proper authorization for purchasing and procurement.
- Periodically re-evaluate cloud resource forms for purpose and fit; updated supplier resource models (for example a newer, smaller IaaS instance) can cut cost with low effort. Detect sub-optimal use of resources.
- Use showback or chargeback reporting to create cost transparency per business unit or stakeholder.

The domain is judged successful when it eliminates bureaucracy (or creates a smooth path through it) and prevents unauthorized IT purchases.
