# Detron Proposition Portfolio (Technology Officer Era)

As Technology Officer at Detron, Bas drove a portfolio of new and in-development propositions. This is a snapshot of his product/proposition thinking around 2017 (pre-GDPR, Office 365 Cloud Voice era).

The propositions:
- **(I)IoT** via partnership with Advantech, focused on OT (Operational Technology) and IT integration: network segmentation, data classification and encryption, security and notifications, secure remote access, restricting internet access. Plus exploration of big data analytics and supporting infrastructure.
- **Detron Secure Datashare** built on Citrix ShareFile (sold as "Detron ShareFile"): secure store, edit and share of data, internal and external, with customer-chosen location (Detron datacenter, own datacenter, Azure). Bas saw GDPR as the timing hook to actively market it.
- **Communications**: Detron selected for the Microsoft Practice Development Program for Office 365 Cloud Voice, building a unified-communications proposition with Microsoft's PDU.
- **Detron Security in a Box - powered by CyberAnt**: an all-in-one vulnerability management scan offering (24/7), aimed at making cybersecurity understandable, accessible and affordable. Driven by rising threats and tightening regulation (meldplicht datalekken, GDPR).
- **GDPR compliancy checker** with Eset, as an enabler for further security services.
- **Other security services** in negotiation: DLP, security scan, social engineering scan, SoC-as-a-Service, plus the In Control proposition (existing security component to be replaced).
- **Hyperconverged** (talks with Nutanix) as part of the hybrid-cloud story: see the separate note on his three hyperconverged use cases.
- **Azure Stack** alongside a Detron cloud redesign (see separate position note).
- **WaaS (Wireless as a Service)** in three tiers (basis, plus, premium): predictable cost, one monthly invoice, no upfront investment, scales access points up/down with the organization.
- **Detron cloud platform redesign**: multiple workspace types from the cloud, a customer portal, heavy back-end automation, multi-cloud strategy, aggregating apps and workspaces from a single console.
- **SaaS services**: Backup-, Archiving-, Storage- and Disaster-Recovery-as-a-Service.
- **Feasibility studies** planned around big data, blockchain, AI and more.

This is durable as career/portfolio context: it shows Bas operating at portfolio/strategy level (the "as-a-service" packaging instinct, the hybrid-cloud worldview) years before CGIT.
