# RES PowerFuse / Workspace Manager (reference)

RES PowerFuse (later renamed RES Workspace Manager) was a user-environment management product for Terminal Server / Citrix environments. It centrally managed the user workspace: global application overview, application parameters, shares, environment variables, printers, and policy/registry settings.

Six of its security and performance modules each had three modes: Disabled, Learning, and Enabled. Learning mode let an admin observe behavior before enforcing it.

This is dated, product-specific reference material from Bas's consultant era.
