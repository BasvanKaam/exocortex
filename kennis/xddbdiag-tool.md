# XDDBDiag: XenDesktop Database Diagnostic tool

XDDBDiag is the XenDesktop Database Diagnostic tool. First designed for XenDesktop version 5 but usable with all newer 7.x editions. This command-line support tool performs a consistency data check and connectivity verification on a XenDesktop database, and is also useful for proactive administration.

Diagnostic output is saved as a CSV inside a compressed file named Computername_XDDBDiag_Output.zip in the program's directory. It provides: Site information, Virtual Desktop Agent information, current connections / connection log, Hypervisor connections, policy information, desktop group, controller information, SQL information, and more. It auto-searches for updates on launch (which can be disabled). Reference: CTX128075.
