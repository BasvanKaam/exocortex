# Nested Governance: Corporate over IT over Cloud

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Beyond the strategic-to-operational hierarchy of purpose, governance itself is nested. Corporate governance (institutional governance in the public sector) supersedes IT governance, which supersedes cloud governance.

Cloud governance therefore inherits and operates within the constraints of the layers above it. This nesting is why cloud governance pursues the same goals as IT governance (compliance with laws and regulations, conformance to existing standards and policies) and why the framework insists you design for cloud within the Enterprise Architecture rather than as a standalone island.
