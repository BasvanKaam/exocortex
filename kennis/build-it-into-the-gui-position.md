# Critique: why isn't this in the GUI? (web.config friction)

Bas's small but pointed product critique (Dec 2013): StoreFront's powerful Multi-Site features all have to be hand-edited in the web.config file, and once you do, some GUI tasks get disabled to prevent misconfiguration. His reaction: 'why not build this functionality into the GUI instead?'. He also points out the lack of Local Host Cache in FMA makes the SQL database a single point of fragility ('And lets be honest, it often doesn't' work as well as clustering/mirroring promise). The stance: Citrix's E-Docs covers the how better than he could, so his value is raising awareness of these hidden-but-powerful features, while nudging Citrix to make them less fiddly.
