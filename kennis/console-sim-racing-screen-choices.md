# Choosing a screen for console sim racing: what actually matters

When picking a display for console-based sim racing (Xbox Series X era, 2021), the metrics to weigh are input lag, refresh rate, reaction/response speed, frames per second, 4K support, and HDR. Some need to be as low as possible (input lag, response time), others as high as possible (refresh rate).

Key practical takeaways from how Bas approached it then:
- 4K is not essential despite the hype; you can be fine without it.
- A higher refresh rate (>144) is nice, but starting around 100 is fine for a non-pro.
- Multiple TV screens and three-monitor setups are not supported on an Xbox, so a single large TV can be the pragmatic console choice over a multi-monitor PC rig.

His own pick: a 4K 55-inch Sony, 100 MHz, 7.6ms input lag, HDR, paired with a Playseat TV Stand Pro that lets the rig slide underneath to get closer to the action.
