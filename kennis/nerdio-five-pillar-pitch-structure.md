# Bas's Nerdio pitch structure: the value-add narrative arc

The way Bas frames a full Nerdio overview for partners and prospects, in a fixed sequence that builds a business case before it ever touches hands-on:

1. **Overview** plus Nerdio-and-Microsoft alignment (Nerdio is built on Microsoft tech, leverages Azure APIs, sold via Azure Marketplace).
2. **Automation the Nerdio way** (simplify and automate the management of AVD: images, profiles, storage, applications).
3. **Optimize AVD** to reduce cost (autoscale, right-sizing, reserved instances, disk swap/shrink, user self-service).
4. **Risk avoidance / resiliency** (security policies, RDP policies, RBAC, multi-region DR, hardened deployment).
5. **Windows 365** (provision, manage, resilience, deprovision of Cloud PCs).
6. **Sustainability** (the CO2/Scope-3 angle).
7. **Hands-on** to close.

The rhetorical move underneath: open with market context ("Microsoft is leading the way"), then position Nerdio as the management layer that extends the native AVD admin experience rather than replacing Microsoft. End every section with a hands-on or proof moment.

Reusable as a template for how Bas sequences a technical value story: context, then simplify, then save, then de-risk, then prove.
