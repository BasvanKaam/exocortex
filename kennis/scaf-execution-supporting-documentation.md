# SCAF Execution Phase Supporting Documentation

Bas lists the documentation relevant during the Execution phase: much of it comes back from the Insight phase, now in definitive form, with room for adjustment always present. The set includes:
- Definitive RACI model / team overview
- Definitive GAP analysis
- Definitive application, data and licence inventory (overall plus optional detail palet per application for modernisation)
- Definitive system inventory (plus approach and rationale)
- Definitive security components overview (plus approach and rationale)
- Definitive network components overview (plus approach and rationale)
- Documented processes and procedures (flowchart and process-recording templates)
- Functional/technical design
- Migration/implementation/adoption plan with timelines
- Communication plan template
- Lessons Learned template
- Definitive training / skill-readiness plan

The migration and implementation plan itself states what happens when, how, by whom, with checkpoints, and lists all teams, tasks, roles, (end)responsibilities and stakeholders including duration and scheduling. It is discussed internally and only set in motion after approval. Bas reminds you not to forget the Lessons Learned document.
