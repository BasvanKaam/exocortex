# Reference Architecture Responsibility Split

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Responsibility for reference architectures is demarcated by level:

- Enterprise Architecture sets up Reference Architectures at the EA level.
- The Cloud Architect compiles/collects Reference Architectures at the cloud platform level.
- The Software Architect drafts Software Reference Architectures.

The CCoE owns the cloud architecture and the associated tooling designs. Because it works in close cooperation with development teams, the rate of change is high and the documentation needs regular updates. Practical setup: keep and publish reference architectures in a version-control tool such as Bitbucket or GitHub with an associated wiki, so the relation between architectures and their blueprints, scripts, and security baselines stays visible.
