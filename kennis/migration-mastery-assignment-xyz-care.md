# Opdracht 9: Migration Mastery - Strategy to Execution (XYZ-Care)

Bas's ninth assignment, set in his recurring case organisation XYZ-Care Health Group, where applications like the EPD (Electronic Patient Record / Elektronisch Patiëntendossier) and the planning tool are needed for daily care. The aim is a structured, risk-aware migration. As with all his exercises, the intent is to spur action beyond just reading the book, doing extra research where needed.

The assignment tasks:
- Run a risk analysis and consider the teams involved; identify risks like data loss, downtime and user resistance.
- Develop a joint IT/business priority list, including low-hanging fruit (easy-to-migrate apps or systems that add immediate value).
- Optional: build a technical and functional design template reusable for future migration projects (use Google for a starting point).
- Make a reverse timeline starting from the 'Go-Live' date, working back through the key events and milestones (compelling events).

Worked solution method: use a PM tool like Microsoft Project; categorise risks by impact and probability; assign teams (IT infrastructure, application management, security, care managers, end users) to mitigate them; run a joint IT/business workshop prioritising core EPD functionality, easy-to-migrate apps with minimal dependencies, and systems delivering direct cost savings or process improvement; design the template for reuse (architecture, security requirements, performance criteria, test procedures); and schedule backwards acceptance tests (incl. AVG/GDPR security tests), data validation, training moments and communication events.
