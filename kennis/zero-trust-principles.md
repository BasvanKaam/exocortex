# Zero Trust Principles

Zero Trust requires that every user and device, regardless of location or prior access, is continuously checked. Devices must meet defined security standards and users get only the minimal access needed (least privilege). All activity is logged and continuously monitored to spot threats early.

Core principles:
- Verify all users and devices before granting access.
- Ensure every device meets the required standards.
- Apply 'least access' and 'least privilege'.
- Log and inspect all data (continuous monitoring).
- Continuous monitoring and behavioural analysis to identify anomalous behaviour of users/devices.
- Use intelligent software for real-time threat analysis and detection.
- Automation and response: e.g. automatic blocking of suspicious activity or alerting security teams.
- Regular evaluation and improvement: Zero Trust is not static and must adapt to new threats and technologies.
