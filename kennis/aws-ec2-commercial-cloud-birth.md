# AWS EC2 (2006): birth of the commercial Cloud

While the internet developed quickly, the core principle behind Cloud computing - shared compute power - remained largely untapped until 2006, when Amazon Web Services (AWS) launched the revolutionary Elastic Compute Cloud (EC2). EC2 let companies rent virtual machines based on their needs instead of investing in expensive physical servers.

The idea for EC2 came from challenges Benjamin Black and Chris Pinkham faced managing Amazon's fast-growing IT infrastructure. They realised that decoupling applications from physical hardware and hosting them in a virtual environment could massively increase scalability and efficiency. The idea was approved by Jeff Bezos, and within 18 months AWS attracted more than 500,000 customers. EC2 let companies scale quickly and manage IT resources flexibly, marking the start of the commercial Cloud as we know it today.
