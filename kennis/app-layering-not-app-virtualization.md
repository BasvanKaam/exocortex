# Framing: keep application layering and application virtualization distinct

Reviewing Liquidware FlexApp in September 2015, Bas is careful to draw a line that was easily blurred at the time: application layering is not application virtualisation. 'Note that this is not an application virtualization solution like ThinApp and/or App-V for example. There is no isolation in play here.' His practical take is that they're complementary, not competing: 'In most cases application layering will be used in conjunction with application virtualization.' A clear conceptual distinction he wanted readers to carry away from an otherwise vendor-driven product overview.
