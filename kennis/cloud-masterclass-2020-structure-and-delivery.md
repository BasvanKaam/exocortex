# Cloud Masterclass 2020: Course Structure and Delivery Style

Bas's 2020 Cloud Masterclass ("Class of 2020") is a two-day, slide-driven classroom training organized around three recurring lenses that label every chapter: Strategie, Inzicht, Uitvoering (Strategy, Insight, Execution). The chapter spine, repeated as a navigation ribbon on each section divider, runs: Er was eens (history) -> Cloud modellen -> De nieuwe zakelijke realiteit -> De Cloud anno 2020 -> Cloud economie -> Architecturen en diensten -> Veiligheid -> Data en Governance -> Exit strategie -> Community en praktische tips -> Toekomst en trends -> Roadmap planning en Cloud adoptie.

Delivery is explicitly framed as no-nonsense: "Duidelijke taal, geen poespas", lots of questions, discussion, whiteboard and peer learning, plenty of breaks, lunch and Red Bull. Each chapter closes with an "In de praktijk" slide that distils field-tested takeaways, and several chapters include timed group exercises ("5 minuten, 2 groepen, klassikaal doornemen"). The deck closes with a resources slide: Avensus Academy virtual hand-out, Bas's own book *Byte-Sized Cloud Design Principles and Architectural Recommendations*, SCAF/Cloud Adoptie Framework material, a reading list, a Slack channel, personal contact with Bas, and links to his blog, events, podcast and a survey.

This note captures the training-specific framing only; the underlying cloud concepts are the same ones distilled from the book.
