# SCAF Handover Checklist (Overdracht Checklist)

A training deliverable from the Cloud Masterclass: a control-measures (controle maatregelen) form used at the end of a cloud project to verify it is ready to be handed over from project to operations. It carries a header (Datum, Ingevuld door, Project naam) and scores each item Ja / Nee / Nvt with an Omschrijving column. It operationalises the Adoptie and "in beheer name" stages of SCAF into a concrete sign-off artifact.

The checklist is grouped into six domains:

1. **Documentatie** - functional and technical design, user manuals, information-security requirements, component list with descriptions, known-errors list, lessons-learned document, all processes documented with owners, test plans (backup, DR).
2. **Processen (ITIL)** - Incident, Problem, Configuration, Change: helpdesk instructed, problem descriptions, process-supporting tooling in use, resolver groups defined, Configuration Items in the CMDB, processes for assignment/progress/resolution.
3. **Dienstverlening (service delivery)** - all SLAs discussed and understood, service levels known, service added to the catalogue, time-writing codes created, maintenance windows recorded, management tooling in use, authorisations created and assigned.
4. **Opleiding (training)** - skills matrix, GAP analysis performed and documented, skill-readiness plan written/started, training tracks mapped, end-user training mapped, budget approved.
5. **Communicatie** - communication plan written, promotion campaigns started, ambassadors / key users appointed plus planning, aftercare agreements.
6. **Overige** - implementation plan present, test plan and test reports present, risks analysed, aftercare planning (floorwalkers, helpdesk).

Each section ends with an open "vul maar aan" (add your own) row, signalling the checklist is meant to be tailored per project rather than treated as exhaustive.
