# SCAF Lessons Learned register

A supporting SCAF artifact that captures lessons from the Execution phase (Uitvoering) so they can be exploited during the Adoption phase (Adoptie), where the bulk of the planned work is completed.

It is a per-project table with columns:
- Category (Application / System / Process / etc.)
- Description of the issue
- Solution or workaround
- Handler / owner
- Impact (High / Medium / Low)

The design intent: capture knowledge while issues are fresh in Execution, then carry it forward into Adoption rather than rediscovering the same problems. A free "other" row lets users add their own categories and remarks.
