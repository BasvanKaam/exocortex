# Bigger cloud providers are not more secure by default

Bas's stance (Inside Citrix, 2016): the big cloud providers are not more secure by default. On average they invest more in security, but the bigger you are, the more interesting a target you become, and eventually attackers find a way. Scale buys investment, not immunity.

*Bron: Inside Citrix (2016), 'Inside Citrix Ch3 - Is the FMA still relevant (cloud vs on-prem)'.*
