# Parallels RAS (Remote Application Server)

Profile of Parallels RAS as a Citrix/EUC alternative (2019).

- RAS = Remote Application Server, made up of multiple components.
- Management plane on-prem (Azure coming soon at time of writing).
- Azure install is automated; on-prem is partly automated using templates.
- Provisioning of RDSH servers is automated, on Azure or on-prem (3-tier or hyperconverged).
- Only one of the three compared that supports a true on-premises deployment of the control plane.
- Strong focus on Mac (Win on Mac); integrations for Turbo Containers and App-V; known for being very transparent with lots of public documentation.
