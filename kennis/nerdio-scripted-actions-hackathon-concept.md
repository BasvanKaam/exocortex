# Nerdio Scripted Actions Hackathon: Bas's Community Event Format

A community hackathon format Bas co-ran (with Neil McLoughlin) as Field CTO EMEA, first edition 2021. The reusable design pattern:

**Core principle (the hook that makes it work).** Every submitted script is made publicly available and free for everyone, with or without Nerdio installed. Scripts do not have to be Nerdio-specific. The framing: "This way we all benefit." Community value first, product second; that is what gets people to participate and share.

**Theme.** Solve and simplify day-to-day challenges around setting up, managing, and (cost) optimizing AVD/AVD (then WVD) and Azure environments, expressed as PowerShell Scripted Actions.

**Structure that makes judging fair and inclusive:**
- Two skill levels, Beginner and Advanced, reviewed and ranked separately with separate prizes. A participant picks one, not both.
- Two tracks: Set Challenges (predefined problems) and Freestyle (bring your own). You may enter both; each is reviewed separately, highest-ranked script wins.
- Judging looks beyond "does it work": originality, use of code, and similar characteristics where it makes sense, because most problems can be solved multiple ways.
- A named review panel ("rock star panel") published up front for credibility.
- Submissions via the participant's own GitHub page (link emailed) plus a mandatory submission template.
- Evidence of a working script required: short video, screenshot, or code output.

**Incentives.** Tiered cash prizes plus swag; a bonus signup package for the first N signups to drive early registration; stickers for every attendee as a reminder.
