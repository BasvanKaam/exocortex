# Citrix Summit 2015: Receiver X1, Framehawk, XenMobile 10

How it worked then (announced Jan 2015, tech previews expected Q1 2015): Receiver X1 ('X1' = experience first) was a fully HTML5-based, web-enabled, centrally managed and centrally brandable Receiver, with an X1-enabled StoreFront server meant to finally replace all Web Interface functionality. Its ambition: one interface across all device platforms, bundling MDX and HDX into a single Receiver (no more juggling Receiver and Worx Home). HDX Framehawk was the headline graphics tech: adaptive orchestration that dynamically adapts to network conditions, demoed delivering content smoothly at up to 50% packet loss, pitched as a game changer for graphics over high-latency, low-bandwidth networks. XenMobile reached version 10, unifying MDM and MAM in a single console with added NetScaler controls and a unified appliance. Other previews: Optimization Pack for Lync, Director Session Recording, XenServer 6.5 (64-bit kernel, ~50% server-density increase), DesktopPlayer for Windows, and the XenDesktop Linux VDA. The CSA (Citrix Solution Advisor) partner program centered on specialization tracks. A snapshot of the Citrix roadmap at that moment.
