# CloudJumper portfolio: CWMS, CW for Azure, and WVD integration

Bas's 2019 review of CloudJumper's three-product portfolio (CW = Cloud Workspace):

- **Cloud Workspace Management Suite (CWMS)**: the core. A cloud-native management platform available only on Azure. From here you configure, monitor and deploy workloads (rights/permissions, Azure snapshots, integrated backup and DR, anti-malware, etc.), either on-premises or in any cloud (Azure, AWS, GCP). For VDI and RDSH you can choose on-premises or any cloud.
- **CW for Azure**: CloudJumper's DaaS offering, Azure-only.
- **Windows Virtual Desktop**: CloudJumper offers a direct WVD integration (the management part on Azure) to automatically configure and deploy WVD machines including Windows 10 Enterprise Multi-Session, Azure only.

CloudJumper was one of the official Microsoft WVD partners, and specifically a 'launching partner' involved in WVD's development from the very start. Beyond Windows 10 MS automation it provides a graphical UI that simplifies setting up a WVD tenant, then one of the few to offer this combined with a DaaS solution.
