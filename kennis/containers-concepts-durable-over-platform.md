# Stance: container concepts carry over from Docker/Linux to Windows

In August 2015, as Microsoft shipped its first native Windows container support in Server 2016 TP3, Bas argues that the deep Docker/Linux container concepts he'd written about earlier (how a container is built and run, its components, kernel interactions, isolation, repositories, pros and cons) are 'still relevant today' for Windows containers. His framing: 'There might be some slight differences... but the overall concepts are pretty much the same.' An early signal that he treats containerisation as a platform-independent set of ideas worth understanding once, a notably forward-looking topic for a Citrix/EUC blogger in 2015.
