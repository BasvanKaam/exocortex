# AVD security cheat sheet: the six-category framework

Bas's AVD security cheat sheet (v2.0, Jan 2024, 44 measures, first published Apr 2023 with 36) is structured as a starting-point checklist, not an exhaustive standard. The reusable contribution is the framework: organise AVD/Azure security measures into six distinct categories, each item formatted identically (Name / Additional information link / Description), so a reader can scan, pick, and follow the link for depth.

The six categories:
1. **Nerdio security checklist** (hardening the Nerdio Manager install itself).
2. **Other (Nerdio) considerations.**
3. **General security best practices.**
4. **Identity and access controls.**
5. **OS, app, and machine-level security.**
6. **Network security.**

Framing principle: "with and without Nerdio." Most items apply to AVD in general; some are paid Microsoft services the reader may already own. Each numbered item is a one-paragraph plain-language explainer plus a link, deliberately not deep, so the sheet stays a usable overview rather than a manual.

This is the same asset type pattern Bas reuses: a versioned, numbered, link-rich cheat sheet with explicit version control (version / date / author / changes) at the top.
