# Local communities and Meetup; Dutch community examples

Bas notes there are many communities closer to home with effectively no entry conditions except being on time before they fill up or start. Meetup is a widely used platform where physical and virtual gatherings are announced and organised; creating an account is free and almost all events are free (the odd exception when a dinner is attached). He rates the presented content as always relevant and of a solid level.

Benefits he lists: independent experts; honest and open (sometimes a bit too much); gatherings, drinks, camaraderie and conviviality; worldwide events; an inexhaustible knowledge source; great willingness to help; market insights/research; often free or cheap; and podcasts, websites, blogs, cheat sheets and books.

Dutch community examples he names (links omitted as communities come and go): Dutch Azure Meetup, Dutch Cloud Native Day, Dutch Virtual User Group, World of EUC, Dutch Microsoft 365 User Group, Dutch Cloud Community, AWS User Group Netherlands, Google Cloud Developer Community Netherlands, OpenStack Nederland, Dutch Citrix User Group, Kubernetes Community Nederland, Nutanix User Group, Nerdio Tech Insider, Dutch VMware User Group, Cloud Technology Enthusiasts, CloudGURUS, DevOps Amsterdam, ExpertsLive.
