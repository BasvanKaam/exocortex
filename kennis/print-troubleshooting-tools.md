# Print-related troubleshooting tools (Print Detective, UPS Cert Tool, StressPrinters)

- Citrix Print Detective: an information-gathering utility for print-driver troubleshooting. It enumerates all printer drivers (with driver-specific info) on a Windows machine, can delete specified drivers, offers log file capabilities and a command-line interface, and supports all Microsoft desktop and server platforms (v1.2.1.5+ supports XenDesktop 7). Reference: CTX116474.
- Citrix UPS Print Driver Certification Tool: tests a print driver's compatibility with the Citrix Universal Print Server by simulating load, verifying the driver can handle normal UPS load, meets UPS performance requirements, and identifying potential issues. Reference: CTX142119.
- StressPrinters: compares print drivers (CPU load, time to create a printer) and simulates multiple sessions auto-creating printers using the same driver. Reference: CTX129574.
