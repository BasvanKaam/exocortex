# Cloud only? No. Cloud first or hybrid? Yes.

Bas's headline position (title of his 2019 Cloud Masterclass essay, which he still endorses in principle): a cloud-only world is a utopia for at least the next 15-20 years, possibly longer. The realistic and sustainable path is **cloud-first or hybrid**, adopted step by step.

The argument is explicitly *not* anti-cloud. The cloud's potential is enormous and the outlook bright; the problem is exaggerated marketing that frames every other approach as obsolete. Consultants and advisory firms should focus on what best fits the situation, 'and sometimes, that might not be the cloud.'

Decision rule: 'Using cloud simply for the sake of using cloud is not a valid reason. Nor is doing it just because everyone else seems to be. The use case must make sense, and it needs to be backed by a solid business case.' Use cloud where it adds real value; if there's no added value, don't move.

Supporting evidence he leans on: Nutanix Enterprise Cloud Index 2019 (73% planning to move workloads back on-prem, citing cost/performance/security/compliance, though he flags Nutanix sells hybrid appliances); the '94%/per cent use the cloud' stat is marketing because it conflates email/Office 365/SAP/HR tools with full datacenter migration. The big providers themselves validate hybrid by bringing cloud-native services on-prem (AWS Outposts, Azure Stack Hub, cloud-to-edge), while containers/Kubernetes and Azure Arc point to portable, single-control-plane hybrid/multicloud governance.

His present-day reflection: tone was more direct and negative than he'd write today, but the core principles still shape his thinking. Closing line of the original: 'Cloud only? No. Not anytime soon. Possibly never.'
