# Service-model preference: SaaS over PaaS over IaaS

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

An innovation-focused cloud strategy leads to a clear preference order:

1. SaaS
2. PaaS
3. IaaS

The logic is that moving up the stack outsources more of the operational burden, so the organization should prefer the highest service model that fits each workload. In reality the strategy is more fine-grained and offers a choice between different target landing zones.
