# Stratusphere UX 6.1: dashboards, event log harvesting, process optimization

How it worked in this 2018 release. Liquidware Stratusphere UX 6.1 added several capabilities for end-user-experience and infrastructure monitoring:

- Custom dashboard builder: build dashboards from scratch with only the metrics that matter, or customize built-in ones, via drag-and-drop widgets. Dashboards can be shared with teams (Helpdesk, Networking) and displayed on big screens/TVs.
- Windows Event Log harvesting: UX can now collect Windows Event Logs into its own tab in the Advanced inspector, with filters by severity, include/exclude by event ID, and aggregation, addressing the local Event Viewer's lack of a visual overview and weak historical grouping.
- Process optimization ("set it and forget it"): prioritizes the in-focus, most actively used application while non-invasively deprioritizing background tasks, to improve UX and desktop density on sub-optimally-sized machines. Works on single- and multi-user Windows workloads.
- BYOL (Bring Your Own License) support for AWS Marketplace and Microsoft Azure.

Plus extensive built-in reporting for technical inventory and management KPIs/SLAs.
