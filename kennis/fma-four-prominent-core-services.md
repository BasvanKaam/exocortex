# The four most prominent FMA core services

Four FMA services take on a more prominent role than the others (a.k.a. core services):

- **Broker Service**
- **Configuration Service**
- **Delegated Administration Service**
- **Configuration Logging Service**

These sit at the centre because the rest of the FMA depends heavily on them for inter-service communication, permissions validation, and configuration integrity.
