# The browser as the aggregation layer / new OS

A recurring industry thesis: as SaaS proliferates, the web browser becomes the de-facto operating system. The power comes from aggregation: pulling web, mobile, and Windows apps plus data and desktops into a single web-based pane of glass.

The zero-trust angle that makes this compelling: the endpoint only runs a browser, the user is never actually 'on' the network, no VPN is needed, and no data sits locally. The whole workspace is pushed to the user inside an encrypted virtual connection with MFA on by default. Even a compromised device gives no direct access to company assets because there is no local data and no open 'pipe' for an attacker.

This also eases BYOD adoption, since the endpoint requirement collapses to 'has a browser'.
