# SaaS only gets you so far; legacy Windows apps grew, not shrank

Bas's stance: SaaS solutions are great but only get you so far. We keep dealing with tons of traditional (legacy) Windows applications for years to come. His 2018 update is pointed: the use of traditional Windows applications grew over the prior two years, it did not shrink. This is part of why RDSH/VDI delivery of Windows apps stays relevant.

On DaaS: a great fit for many, but for a bunch of companies DaaS is too restrictive or limited in what they can do or control themselves. Most DaaS in 2016 was RDSH/XenApp-based shared desktops; the 2018 note adds that it can be Windows 10 too (Microsoft CSP licensing model), and that true 1:1 desktop-OS VDI from the cloud, once blocked by Microsoft licensing, was no longer blocked by 2018.
