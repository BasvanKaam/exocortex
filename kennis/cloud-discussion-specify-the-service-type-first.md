# Before debating Cloud, specify which type of service you mean

A recurring point of his: 'Cloud' is too often used as a single undifferentiated word, without specifying the type or sort of service involved. This makes any discussion about what works and what doesn't extremely difficult. The advice is to first specify the type of services you are dealing with (SaaS, IaaS, DaaS, PaaS, RaaS, and private vs public vs hybrid) before anything else. Cloud can make life a lot easier but also very complex if you are not careful.

Durable communication discipline that still holds: name the layer before arguing about the trade-offs.
