# WVD hit general availability on September 30, 2019

Fact Bas anchors his six-month retrospective on: Windows Virtual Desktop reached general availability on September 30, 2019. By April 2020 he frames the first six months as heavy optimization work by Microsoft's WVD/RDS team(s), partly with the help of technological partners.

Dated (WVD was later renamed Azure Virtual Desktop), but useful as a fixed timeline marker for the EUC era. The full retrospective lived on brianmadden.com.
