# Receiver for Mac vs Desktop Player: online versus offline

How it worked then (2014): Citrix Receiver for Mac let you access published apps, Hosted Shared Desktops or VDI desktops from a Mac via XenApp/XenDesktop, but its drawback was that you had to be online. Desktop Player for Mac complemented this by offering offline access to Windows virtual desktops, fully isolated from the rest of the Mac, with the VMs running on a local type-2 hypervisor so they get local compute resources for better performance.
