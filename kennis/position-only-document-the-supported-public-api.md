# Only the Documented, Supported API Counts; Internal APIs Are Out of Bounds

Bas takes a firm governance stance on how an API should be taught and used: the only legitimate surface for external integration is the documented, supported public REST API. Internal platform APIs, backend workflows, and reverse-engineered or undocumented endpoints are explicitly out of scope and out of bounds. He builds this into the training as an explicit scope boundary precisely to avoid people conflating the platform's internal APIs with the public one. The corollary: responsible long-term API use means tracking deprecations and documentation/release-note changes, not relying on whatever currently happens to work.
