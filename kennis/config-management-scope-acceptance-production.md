# Scope configuration management to Acceptance and Production

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Practical scoping guidance for cloud configuration and asset management:

- Focus on Acceptance and Production environments rather than the complete DTAP street.
- Routinely compare different sources of configuration and asset information to find discrepancies; this is a means to improve both the data and the process. Plan periodic exception reporting based on contrasts in overlapping data sets.

CCoE responsibilities: configuration and asset management responsibilities stay in place; the CCoE is responsible for tagging implementation and for monitoring compliance on tag use, and creates the reports and dashboards for process management.
