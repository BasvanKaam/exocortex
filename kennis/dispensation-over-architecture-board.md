# Facilitate Change, Don't Block It

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

His stance: an IT organization should facilitate the rapid development and innovation coming from cloud teams, not get left behind by it. Rather than gatekeeping architecture change, you give teams a dispensation process so changes can flow.

The dispensation request is reframed positively: not a nuisance, but the very signal that keeps a reference architecture honest. One request triggers maintenance; a pattern of requests triggers a review of whether the architecture still fits reality. Governance here exists to keep documentation current and debt low, not to slow teams down.
