# New FMA features go to the cloud first

In this Aug 2016 news round-up Bas notes the pattern that new FMA features go "live" in the cloud first before reaching the on-premises XenDesktop/XenApp editions, and speculates Citrix would take a similar cloud-first approach with XenApp Express. He also voices a personal preference about resource locations: currently only the customer's Azure subscription qualified, and he openly hopes on-premises becomes an option too ("I hope so"). His framing positions Citrix Cloud as the leading edge and on-prem as the follower, an accurate read of where the industry was heading.
