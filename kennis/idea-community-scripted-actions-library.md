# Idea: crowdsource the Scripted Actions library from the community

Community-contribution model for the Scripted Actions library: invite the community to submit scripts that add value to WVD, to be published in the shared library. Contributors get full credit; submitted scripts may be lightly adapted to house standards, with the author always reviewing before publication. The longer-term vision is a community effort around plugging anything and everything into WVD via the platform as building blocks. Reusable pattern: build the product's value library with the community rather than only in-house, with credit and review as the trust mechanism.
