# XP end-of-life is the moment to innovate, not just migrate

Bas's stance (Nov 2013, ahead of April 8 2014 XP EOL): thousands of companies still run XP and must act now, because once extended support ends there are no more fixes or security updates and 'we can do about it except to dump XP'. But he reframes a forced migration as an opportunity: since you'll need new hardware anyway, this is the moment to rethink and innovate (VDI, DaaS, Hosted Shared) rather than just swap XP for Windows 7 on the same fat-client/SCCM model.

His guardrail against hype: 'don't just go with VDI because it sounds sexy!' It isn't up to IT alone; involve users from the start and let the business case and user acceptance decide. His recommended flexible product if you do want it all under one roof is XenDesktop 7. The position blends urgency with a warning against over-engineering.
