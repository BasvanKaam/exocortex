# Three Cloud Providers in One Line Each

Bas's shorthand characterization of the three big public-cloud providers, used to frame a 2020 cloud webinar:

- GCP: developers.
- AWS: big, but everything separate — "een bij elkaar geraapt zooitje" (a thrown-together bunch).
- Azure: integration.

A fast positioning device for a general cloud audience. Time-bound: a 2020-era characterization of the provider landscape.
