# Information a cloud deployment request must capture

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Whatever shape deployment requests take (scripts, forms, etc.), they should capture:

- Application (number and/or name)
- Application role (OTAP / DTAP stage)
- Part of cluster
- Software versions
- Application owner
- Cost code (project, department, or unit to allocate cost to)
- Deployment requester
- CIA classification (confidentiality, integrity, availability)

Governance practice for this domain: communicate why the process matters and how it is performed, and report on automation/labeling effectiveness, asset and configuration accuracy, and success in allocating cost and detecting compliance and security risks.
