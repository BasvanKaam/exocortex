# SMS-based 2FA remains practical, secure and user-friendly when done right

In Oct 2016 Bas declares himself a long-time fan of two-factor authentication, especially SMS-based 2FA: easy to set up, configure and maintain, very user-friendly, secure when properly implemented, and crucially no expensive third-party tokens (just use the phone people already own). He concedes everything can be hacked and SMS intercepted, but quotes SMSPassword founder Dennis Smith's argument that an attacker must compromise two separate networks at once and have both the (regularly-changing) domain password and a short-TTL one-time password simultaneously. His conclusion: "SMS based 2FA isn't going anywhere any time soon." Worth dating: this predates the later industry shift away from SMS OTP toward app/FIDO factors, so it captures the pre-2017 consensus that SMS 2FA was good-enough security.
