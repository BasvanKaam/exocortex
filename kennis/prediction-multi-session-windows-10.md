# Prediction: a multi-user version of Windows 10 is coming

March 2018: with RDSH apparently not working in the Server 2019 preview and Microsoft staff (incl. Jeff Woolsey) coyly saying RDS is 'not gone' and 'we'll have lots more on the subject soon,' Bas reads the tea leaves. His stance: RDSH/multi-user is far too popular to disappear, but Microsoft may be moving it off the Server OS, and 'perhaps that's where we'll find it next' on Windows 10 as a multi-user/multi-session desktop. He argues there is no technical reason Windows 10 can't host multiple user sessions ('the code is already there'), only software and licensing changes, and that licensing 'should be the easy part.' This proved prescient: Windows 10 Enterprise multi-session shipped with Windows Virtual Desktop in 2019. He pairs it with RDmi (PaaS RD backend on Azure) and the Citrix partnership as evidence of Microsoft's broader push to the Azure cloud.

*Bron: blogpost 'Windows Server 2019, but no RDSH? A Multi-User version of Windows 10? What's going on?' (2018-03-26), basvankaam.com.*
