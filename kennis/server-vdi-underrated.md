# Server VDI is an underrated, overlooked feature

In January 2014 Bas's take is that Server VDI "hasn't really gotten the attention it deserves" despite being available since XenDesktop 5.6. He finds it surprising the feature wasn't talked about more given the flood of DaaS announcements, especially Amazon WorkSpaces, since it is precisely the mechanism that enables true one-to-one cloud VDI on a server OS.

He's honest about its limits: valid use cases are narrow if you're not a service provider, and it is not a cost saver. But he flags it as worth knowing about. The trigger for the article was a colleague hitting Server VDI's limitations in a POC, which is a recurring pattern in his writing: real-world incidents drive his deep dives. In replies he stays appropriately humble about technical certainty: "I'd really need to (double) check before commenting again, haha, before I say something else that may or may not be true."
