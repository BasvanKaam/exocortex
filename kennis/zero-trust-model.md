# Zero Trust Security Model

Zero Trust is a security model that assumes no one, inside or outside the network, is automatically trustworthy. Instead of granting trust based on location or network access, every form of access is checked and validated. The goal is to ensure only authorised users and devices reach specific data and systems.

Zero Trust focuses on a 'protect surface': a smaller, secured zone of the most valuable and critical parts of the network, namely Data, Applications and Services (referred to as DAAS, explicitly not DaaS). Because this protected zone is much smaller than the whole network (the 'attack surface'), it is relatively easier to secure and monitor.

A major advantage: it can be implemented without large changes to existing infrastructure. Instead, you add security layers that regulate and control access, strengthening security without fundamentally changing the architecture.

Guiding principle: "Nooit vertrouwen, altijd verifiëren" (never trust, always verify).
