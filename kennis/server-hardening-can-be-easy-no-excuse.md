# Server hardening can be easy — so there is no excuse

Bas's stance: people treat server hardening as hard and therefore skip the basics. LAPS proves parts of hardening can be straightforward. Once a free Microsoft tool fully automates unique, rotating local-admin passwords with no extra server role, there is no longer any excuse to leave local-admin password management badly arranged. The unmanaged, over-privileged local administrator account is a real risk, and the fix is simple — so do it.
