# Cloud is still more reliable than on-prem, be realistic about it

From a short draft (October 2020) reacting to a run of global Azure outages, Bas's honest position:

- You can design around some failure (regions, availability sets/zones), but not everything; some core-service outages can't be designed away.
- 'Go on-prem then' isn't an escape: if you use Office 365 for mail (he notes 50%+ do), you're still stranded; the same applies to multi-cloud.
- Cloud is still relatively new and a learning process, with different SLAs; Azure is growing strongly and Covid drove heavy demand and challenges. With so much being added and changed constantly, things will occasionally break.
- Even so, cloud is online more often and has fewer outages than on-prem, whatever people claim. Be realistic and admit it. He notes he himself thought differently about this a few years ago, at least partly.

This is an unfinished outline (mostly Dutch shorthand), but the stance is clear and consistent with his later thinking.
