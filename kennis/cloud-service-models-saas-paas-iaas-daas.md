# Cloud service models: SaaS, PaaS, IaaS, DaaS

The book lists the cloud service models relevant to RDSH/VDI delivery:

- PaaS (Platform as a Service): e.g. Citrix Cloud, from which admins can select and deliver complete Citrix-orientated workspaces 'as a service' with a few clicks, without designing, installing or updating infrastructure manually. There is still configuration and ongoing management to do.
- IaaS (Infrastructure as a Service): you still set up, configure and manage your own servers/OS; XenApp/XenDesktop still has to be installed and managed by your own admins.
- DaaS (Desktop as a Service).
- SaaS (Software as a Service).

In the book's 'Cloud services overview' diagram, the darker grey fields indicate what still needs to be managed by your own IT department. Citrix Lifecycle Management can help manage on-prem or cloud-based VDAs.
