# Come Get IT Event Production Playbook

Durable operating model for running a recurring community/tech event, distilled from a Come Get IT post-mortem.

## Lessons learned (what to fix next time)
- Tighten the schedule and communicate it clearly in the agenda: gather from 17:00, eat at 17:30, into the room between 18:15 and 18:30, start at 18:30.
- Give externals (clients, partners, other interested guests) a different colored name badge than internal staff.
- Cap sessions at max 3, each 25 to 30 minutes; prefer 25 minutes plus 5 for questions. Use a fixed session format.
- More attention to detail in prep: too much did not go to plan or ran over. Build a fixed step-by-step plan (draaiboek) with a clear schedule set in advance.
- Personal, individual invitations matter: attendees specifically appreciated being invited in person where feasible. Maintain a running list of names.
- Do not lock the registration list to a single person; shared access is needed.
- Set up a WhatsApp group for the organizing team for fast coordination, plus a mail group for longer correspondence.
- Make responsibilities and expected arrival times explicit and aligned up front.
- Optional: once the draaiboek is ready, send separate calendar invites including a description of the agreed arrangements.

## Draaiboek (roles and responsibilities)
Structured as before / during / after, with named owners:
- Agenda / speakers: owner A
- Save the date, food, location, equipment (microphone, connectors): logistics owner
- Invitation and pre-event communication (website, program/speaker promotion): shared
- Host (gastheer), hostesses (min. 2), badges, speaker gifts, handout for attendees: assigned per person
- Shared registration list / mailbox access
- Kahoot quiz with a prize as an engagement device

## The reusable principle
Assign every task an explicit owner, write it down in a draaiboek, share access to the critical lists, and debrief after each event to feed the next one.
