# The Liquidware portfolio in 2017: Stratusphere, ProfileUnity, FlexApp

How it stood then. Liquidware's EUC portfolio at the time Bas joined comprised three products. Stratusphere UX: desktop and user-experience monitoring, giving visibility across all users, machines and applications, using a user-centric performance metric to define 'normal' and manage users through their lifecycle. ProfileUnity: User Environment Management covering application lifecycle, rights management and support for ongoing/automated Windows migrations, going beyond basic profile management to full user-environment control including profile portability. FlexApp: application layering, choosing the most effective app delivery/deployment mode while tracking application age, versions and licensing. Liquidware positioned itself as vendor-independent and platform-agnostic: on-premises, physical, virtual and cloud.
