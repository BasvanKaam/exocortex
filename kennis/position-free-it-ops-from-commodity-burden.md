# The point of cloud strategy is to free IT from commodity toil

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The framework frames the high-priority goal of a cloud strategy as relieving IT operations from the burden of maintaining commodity applications that provide limited competitive advantage. Keeping-the-lights-on costs on these applications are high while the upside is low. The strategic move is to push commodity functionality to SaaS/BPaaS so scarce time and money are redirected to the applications that actually differentiate the organization. Cloud is a means to reallocate resources toward competitive advantage, not an end in itself.
