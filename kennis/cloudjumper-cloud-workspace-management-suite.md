# CloudJumper Cloud Workspace Management Suite (WVD GUI)

Profile of CloudJumper as a Citrix/EUC alternative (2019).

- The Cloud Workspace Management Suite is their crown jewels.
- Control plane is **Azure only**; workloads run on cloud and on-premises.
- They are a Microsoft WVD partner and built a graphical UI around WVD.
- Deployment of workloads (WVD, VDI, RDSH) is fully automated on cloud and on-prem; they call it the 'Easy Button for Azure'.
- Document management via OneDrive and Azure Files; profile management via UPD/FSLogix; multi-tenant.
- Extras: Citrix and RDS migration tools, auto power down, wake on demand, Live Scaling, auto FSLogix install/config script, strong IGEL partner.
- Commercials (2019): the CW Management Suite was free until Jan 2020; usage is free, Azure resources cost money.
