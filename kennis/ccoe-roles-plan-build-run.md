# CCoE roles: general, Plan-and-Build, and Run

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The Cloud Center of Expertise (CCoE) is a cross-functional, agile team with co-located dedicated members that facilitates existing (DevOps) teams. Its purpose is to enable teams and business units to use and leverage cloud technology on-demand in a fast, secure and governed manner, by bringing cloud competencies, knowledge, best practices, tools, education, solutions and services to those value teams so they can focus on creating value.

The CCoE has two parts: the left part ('Plan & Build') focuses on the teams and the business, facilitating effective use of cloud technology; the right part ('Run') focuses on operational activities. The crucial roles, grouped by part:

- **General roles:** CCoE Leadership (Product Owner), Scrum Master, Agile Coach.
- **Plan & Build:** Cloud Consultant, Cloud Architect, Cloud Security Specialist.
- **Run:** Cloud Admin, Cloud Developer, Cloud Analyst.

Roles can be combined and performed by one person: the most experienced Cloud Architect might also fulfil the Leadership role, and the Cloud Security Specialist role can be performed by a senior Cloud Admin. The exact layout and sizing should be based on demand, which differs between a large cloud migration and a cloud-native development effort.
