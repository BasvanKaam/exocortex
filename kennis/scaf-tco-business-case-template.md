# SCAF TCO / Business-case template

The SCAF TCO / Business-case template is a set of overviews bundled in a single Excel document, providing a guideline for building a full business case in the Step-Cloud Adoptie Framework.

It begins with an inventory of current costs (TCO), covering all cost items of the existing infrastructure: applications, development, maintenance, licenses and virtualisation. It then offers options for **application refactoring**, presenting choices between SaaS, PaaS, DaaS, IaaS or other solutions based on earlier-collected data to determine the optimal transition option.

It continues with **transition costs** (one-off spend for development, data migration and temporary overlap between old and new environments), and an estimate of expected operational Cloud costs (TCO), accounting for usage hours, maintenance, licenses, number of users and data volume. A **ROI** section analyses the difference between current TCO and Cloud TCO against the one-off costs. It also describes qualitative variables hard to express in numbers, such as flexible scalability, location- and time-independence, and the pay-per-use model, which calculators can clarify further.
