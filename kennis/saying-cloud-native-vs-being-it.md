# Bas: Saying You're Cloud-Native vs Actually Being It

A characteristic Bas distinction: for a software developer, claiming to be Cloud-native and actually being it are two very different things. He stresses that people throw the term around loosely, but true Cloud-native means operating at a higher abstraction level, API-driven, loosely coupled, OS-independent and extremely scalable. Spinning up a VM (an IaaS pattern) is not Cloud-native, even if it was produced via IaC code.

Source quote: "Dus, zeggen dat je als software ontwikkelaar Cloud native bent en het ook echt zijn, daar zit nogal een verschil tussen."
