# Microsoft CDL (Companion Desktop License)

The **CDL = Companion Desktop License** is a Microsoft license that comes at an additional charge and is not included in the SA program. It lets a user access a Windows desktop OS based VM (on the corporate network) from up to **four** different devices, including iOS and Android tablets (BYOD). The VDA license still needs to be taken care of for this to work legally.

CDLs are mainly relevant with **device-based** SA/VDA licenses, which are the more restrictive option and limit you to roaming rights. With **per-user** SA/VDA licenses these limitations don't apply: Windows can be locally installed on any device running Windows 7/8/8.1/10 Pro or Enterprise (or a Windows tablet up to 10.1 inches), users get access from all their devices internally and externally with no additional CDLs or VDA purchases needed.
