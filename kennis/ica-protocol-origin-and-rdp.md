# ICA protocol origin and the birth of Microsoft RDP

The ICA (Independent Computing Architecture) protocol originated with Citrix Multiuser around 1990/1991, making it over 25 years old at the time of the book. Citrix built ICA from the ground up as the main ingredient of Citrix Multiuser 1.0, allowing multiple users to remotely access software from a server.

Around the time Multiuser shipped, Microsoft announced a move from OS/2 to Windows, leaving Multiuser 1.0 useless without major rework. Investors (including Microsoft) kept Citrix alive, leading to Multiuser 2.0 (1992).

Citrix signed a license agreement with Microsoft (renewed multiple times) to use the Windows NT 3.5 source code to build a more robust protocol, improving ICA (already patented by Citrix). Citrix turned Windows NT into a multi-user platform. With a renewed agreement Microsoft licensed Citrix's ICA for Windows NT 4.0, 5.0 onward, and gained the opportunity to build a competing protocol: this is where Microsoft's **RDP** protocol originated, based on Citrix's technology and ideas.
