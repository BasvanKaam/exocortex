# Workspot cloud DaaS

Profile of Workspot as a Citrix/EUC alternative (2019).

- Cloud-based VDI (DaaS) for desktop and workstation (GPU).
- Control plane is Azure only (also AWS in the US); workloads run on cloud and on-prem (3-tier or hyperconverged).
- Microsoft WVD partner; their strength lies in automation.
- Fully automated deployment of WVD/VDI/RDSH workloads.
- Also offer App Cloud and DRaaS.
- Founded by ex-Citrix and ex-VMware executives; positioned as a direct competitor to Citrix and VMware.

*Bron: Salomon-IT '5 alternatieven' (CGIT Event).*
