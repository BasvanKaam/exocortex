# Citrix Project Accelerator as a guided design tool

How it worked then (2014): Project Accelerator was a free Citrix web tool (login with My Citrix credentials) to guide admins to a successful XenDesktop, XenApp or XenClient deployment, from a few dozen to thousands of users (deliverables designed for projects under 5,000 users). It followed Citrix best practices to recommend hardware sizing, storage, IOPS, RAM, CPU, network throughput, user groups and applications, then produced a deployment plan and architectural layout. Flow: an Assess phase (define organisation, users, applications, priorities like BYOD/security/cost) via the XenDesktop Assessment Wizard, then Design. A Deploy feature complementing the Citrix Consulting Methodology was planned but not yet shipped. It supported XenDesktop 5.6 and 7.1 (7.1 only partly, roughly 75%); XenApp was not selectable at the time because XenApp and XenDesktop had merged under FMA at 7.x.
