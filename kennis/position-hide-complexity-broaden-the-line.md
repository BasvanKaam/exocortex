# Hide the Complexity, Broaden the Line Between UX and Cost

A durable Bas positioning line that predates the AVD rename and still holds: cost optimization vs. user experience looks like an eternal dilemma, but the goal is to *broaden* the normally thin line between keeping users happy and saving cost — give admins enough resources but not so many that they sit unused (wasteful and expensive). The product value is hiding complexity behind a clean GUI so almost any IT employee can run virtual desktops, while leaving PowerShell/Azure portal access intact for those who want it. 'We hide the complexity, add a large degree of efficiency, and make sure nearly every IT employee in your organization can work with WVD.'
