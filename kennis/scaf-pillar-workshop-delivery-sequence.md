# SCAF per-pillar workshop delivery sequence

The Masterclass teaches a repeatable facilitated cadence for working each SCAF pillar with a client, a delivery method layered on top of the framework itself.

Strategy pillar: kick-off (scope, stakeholders, teams), Workshop 1 (drivers, objectives), data processing (intake form, SWOT, strategy map), interviews, Workshop 2 (discuss first findings), Workshop 3 (define and record the CCoE), optional strategy-pillar final report.

Insight pillar (the most extensive of the four): Workshop 1 (plan, participants, existing inventories), interviews, run Wave 1/2 (classification of data and applications), Workshop 2 (discuss outcomes, first cloud impression via the 6 R's), GAP analysis plus Skill Readiness plan, experimentation, business case, then a Go/No-Go decision moment and optional report.

Execution pillar: Workshop 1 (Wave 3 apps/datasets, lock in choices), start minimal governance, kick off Skill Readiness and user training, write technical/functional design and detailed migration/implementation plan plus exit strategy, Workshop 2 (planning, scheduling, procurement, migrate first workload), communication plan live, optional report.

Adoption pillar: Workshop 1 (evaluate execution phase), build new environment and migrate/test, close lessons-learned, make governance/teams/processes operational, hand over to managed services or in-house, final report and presentation, plan gaps/training, evaluation, lifecycle/roadmap.

Work in iterations; inventory rarely succeeds in one pass.
