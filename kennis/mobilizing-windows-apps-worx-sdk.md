# Adding mobile gestures to Windows apps via the Worx App SDK

How it worked then (2014): combining XenMobile with XenDesktop 7.x or XenApp 7.5, IT could mobilize standard Windows applications. Windows apps by default support none of the mobile affordances (pop-up keyboards, swipe, touch options). Using the Citrix Worx App SDK that functionality could be added to normal Windows applications to improve the mobile user experience.
