# Data unit hierarchy from bit to Geopbyte

Reference ladder of data units (each step is 1024 of the previous):

- 8 Bits = 1 Byte
- 1024 Bytes = 1 Kilobyte
- 1024 Kilobytes = 1 Megabyte
- 1024 Megabytes = 1 Gigabyte
- 1024 Gigabytes = 1 Terabyte
- 1024 Terabytes = 1 Petabyte
- 1024 Petabytes = 1 Exabyte
- 1024 Exabytes = 1 Zettabyte (= 1 billion Terabytes)
- 1024 Zettabytes = 1 Yottabyte
- 1024 Yottabytes = 1 Brontobyte (= 10 quadrillion Terabytes)
- 1024 Brontobytes = 1 Geopbyte
