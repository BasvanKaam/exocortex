# Bas deconstructs the cloud promises

In his paper Bas takes the marketing "promises" of cloud one by one and grades each. Cloud is sold as flexible, infinitely scalable, cheap, pay-only-for-use — but the seasoned consultant/architect sees through most of the marketing.

- **Cheaper** — not by definition. Pay-per-use gets more expensive the longer it runs; multi-year commitments (1/3/5 yr) unlock big discounts. Don't forget one-off transition/migration costs. People talk Opex, but there's more to it — often clear too late. The real win lies elsewhere: shorter time-to-market, instant availability, offloaded management, scalability, temporary use, flexibility.
- **Safer** — agreed. Few organisations can spend hundreds of millions a year on security.
- **Instantly available** — agreed, but depends on the service; spinning up 1,000 VMs still takes time (call your vendor rep first for big numbers).
- **Easy to use** — not fully agreed; very service-specific. True for SaaS (fill a form, leave credit-card details, go). With IaaS you still maintain all software; only hardware and hypervisor fall away.
- **Infinite scalability** — partly true, but datacenter limits are appearing.
- **Reachable everywhere** — agreed; a working internet connection is the only requirement.
- **Always available** — sadly no; outages aren't unusual and cost production time.
- **Standards** — barely exist; APIs come closest. There is real cloud vendor lock-in, which is why a cloud exit strategy matters.
- **Management offloaded** — depends; for a modern digital workspace the customer/provider still maintains OS, apps, and data integrity/security (DaaS, PaaS, especially IaaS).
- **Innovative** — absolutely.

Bas's summary: using cloud just to use cloud is not a valid reason, nor is using it because you think everyone does. The use-case must be correct and substantiated.

> Cloud gebruiken om het Cloudgebruik is geen valide reden.
