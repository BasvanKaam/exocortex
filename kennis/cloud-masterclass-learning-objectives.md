# Cloud Masterclass: learning objectives

After the Masterclass the learner should be able to: take their own or a client's organization toward the cloud step by step using a practice-tested cloud adoption framework (SCAF); recognize what changes in an organization when adopting cloud services; explain what cloud governance is and how to start; bring "business" and "IT" closer together and use shadow IT as an enabler; explain the role of the AVG (GDPR) in placing data in the cloud; explain what a cloud exit strategy is, give examples of why it matters, and how to begin one; explain Zero Trust and why to apply it; build a high-level financial business case and name the variables involved; and state the primary differences between the various cloud providers.

These objectives define the consulting capability Bas is teaching, distinct from the book's content.
