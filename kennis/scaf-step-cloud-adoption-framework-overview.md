# SCAF: The Step-Cloud Adoptie Framework Overview

The Step-Cloud Adoptie Framework (SCAF) is Bas's own framework for adopting cloud technology in a structured, strategic way. He explicitly chose a different approach than existing vendor frameworks (Microsoft, AWS, etc.), though those can still be used alongside it. SCAF consists of four phases:

1. **Strategie:** determine a clear vision and goals for cloud adoption; define the business and technological benefits and align the cloud strategy with the business strategy.
2. **Inzicht (Insight):** gain detailed insight into the current IT environment, organisational needs and possible obstacles, enabling realistic expectations and anticipation of challenges.
3. **Uitvoering (Execution):** concretely realise the cloud strategy — technical implementation plus guiding teams in using new technologies — so migration runs smoothly.
4. **Adoptie:** the most crucial phase — ensuring the whole organisation embraces the new ways of working and maximises cloud benefits. Training, communication and change management are key.
