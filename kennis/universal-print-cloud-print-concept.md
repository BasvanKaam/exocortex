# Universal Print: moving print to the M365 cloud

How it started, March 2020: Microsoft announced the private preview of Universal Print, positioned as a 'modern' print solution. The core idea is to simplify printing by moving key Windows Server print functionality into the Microsoft 365 cloud, so organizations manage their print infrastructure as a cloud service rather than running on-prem print servers.

The durable concept under the (now-dated) preview details: print management is another on-prem server role being lifted into the cloud / M365 control plane, part of the broader shift of traditional Windows Server infrastructure roles toward SaaS-style cloud services.
