# Cloud Webinar Structure: Workspace vs Infra Through a Shared Lens

Format for the "Samengroeien" cloud webinar (Salomon x Vijfhart), splitting cloud into two parts — workspace (Bas) and infrastructure (Marcel Kornegoor) — and walking both through the same set of lenses.

General intro: where we stand in 2020, cloud mindset, the three big providers, and the NIST definition, applied to both workspace and infra.

Both speakers cover the same recurring questions for their domain:
- What NIST means for the domain
- Dealing with DATA
- Exit strategy
- Lock-in and how to escape it
- Similarities and differences
- Management/operations (workspace: Intune, third-party, AWS Workspaces, Windows Virtual Desktop; infra: Terraform, Ansible, ARM/CloudFormation)
- Costs

The value is the symmetrical lens: forcing both the workspace and infra story through NIST, data, exit, lock-in, differences, management and cost makes the two halves directly comparable.
