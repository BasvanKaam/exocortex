# Tagging policies as the cloud asset-management mechanism

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Since a central CMDB cannot stay accurate in the cloud, compliance with deployment and tagging policies is enforced through automation: automated deployments, automated configurations, and strict tagging policies.

Tags are used extensively to label instances and serve many purposes:

- Allocate cost
- Register support contact(s)
- Record data-privacy sensitivity
- Record application security sensitivity

Tags are also indispensable for operational management. For example, finding all databases of a certain version so they can be patched becomes trivial when tagging is in place.
