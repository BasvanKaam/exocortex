# Cloud makes an accurate central CMDB impossible

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The ease with which resources get deployed in the cloud is easy to underestimate. The analogy is virtualization: it was expected to deliver greater utilization of existing hardware, but because deploying an instance became so easy it instead led to an explosion of virtual servers (and ultimately more hardware). The result was not a lower total cost but a lower cost per instance, plus a chaotic landscape and an out-of-date configuration database.

Maintaining an up-to-date CMDB has always been very difficult; cloud services make an accurate central database effectively impossible. From a governance standpoint this matters because the aim is to ensure IT budget and resources are well spent and that no undue risk is run. The core aim of this domain is to prevent resources being deployed manually and/or improperly labeled.
