# Windows 365 Cloud PC - Business vs Enterprise

Windows 365 Cloud PC comes in two variants:

**Business:** aimed at small to mid-sized businesses with a maximum of 300 users. Easy to set up, requires no deep IT knowledge, and Intune integration is optional — a large part of management can be done via the native Azure portal. A good fit for organisations without an extensive IT department or deep expertise.

**Enterprise:** intended for larger organisations or companies with more complex IT needs. Requires integration with Microsoft Endpoint Manager (Intune) and offers more control over overall setup, security and network integrations. Suited to organisations wanting strict control over their work environment, security and applications, and those integrating Cloud PCs with existing infrastructure (especially Intune).
