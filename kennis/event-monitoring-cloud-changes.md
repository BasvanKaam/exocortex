# What changes for event monitoring in the cloud

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Adapting event monitoring and incident management for the cloud means accounting for several changes:

- The flow of event data changes.
- Monitoring tooling changes.
- Service chains look different.
- An MSP might be introduced into the service chain, or an existing one replaced.
- Not all cloud providers offer a (live) Service Desk (see Gateway to Vendor Support).

The concern is not rebuilding the entire process: a mature process should be able to handle these changes.
