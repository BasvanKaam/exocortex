# FlexCast delivery technology, worker types and delivery models

FlexCast is a core part of the FMA: a strategy for delivering desktops and applications, offering several delivery models matched to different worker types (as Citrix calls them). Examples: Task Workers (small set of apps but critical data, may suit a local VM) and Road Warriors (need access from anywhere, may suit hosted VDI or hosted shared desktop). You choose the model that best fits the use case.

FlexCast desktop delivery models:
- Hosted shared desktops, non-persistent.
- Hosted VDI: random non-persistent, static non-persistent, static persistent.
- Remote PC (physical PCs only).
- Streamed VHD, PVS.
- Local (existing) virtual machines.
- On-demand (published) applications.
