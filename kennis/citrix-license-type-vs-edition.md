# Citrix license type vs edition vs consumption model

In the XenApp/XenDesktop 7.x era three distinct licensing concepts were easy to confuse:

- **Product ID**: XDT (XenDesktop) or MPS (Metaframe Presentation Server, the legacy code name still used for XenApp).
- **License (consumption) model**: User/Device or Concurrent.
- **License type** = Product ID + consumption model.
- **Edition**: Advanced (XenApp only), VDI (XenDesktop only), Enterprise, Platinum.

XenDesktop offered both User/Device and Concurrent; XenApp sold separately was Concurrent only. Buying XenDesktop Enterprise or Platinum included use rights to XenApp, so User/Device licenses could be used with XenApp too ("Citrix won't even know the difference").
