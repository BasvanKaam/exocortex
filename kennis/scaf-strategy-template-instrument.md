# SCAF Strategy-phase template as a consulting instrument

Beyond the SCAF concepts in the book, the Strategy-phase template is the actual working instrument Bas hands to consultants. Explicit guidance: always use the templates together with the book; the document is a guide and a place to store collected information; use it fully, partly, not at all, or just for inspiration, and adapt freely.

Structure of the strategy template:
- Supporting documents: Strategy Map (PowerPoint) and SCAF SWOT Analysis (Word).
- Mission, vision, core values capture (filled with the client's statements).
- Interview/workshop section: personal details + a structured question battery.
- Discussion section: where to record what was challenged, why, what was discussed, the outcome, and how to proceed.
- Points of attention block (his standing arguments on business-IT).
- Visual business-IT alignment representation.
- Summary written in prose for the final report.
- Reporting via Management Summary Palettes (one palette per SCAF phase/process, available as Word documents) so interim results can be presented per phase rather than only at the end.

The template carries a tabular intake: person/role/department/date, plus a 'drijfveren' (drivers) table scoring each reason L/M/H by priority.
