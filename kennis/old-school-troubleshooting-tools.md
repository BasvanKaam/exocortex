# Don't forget old-school tools (NetStat, Ping, Tracert, Telnet)

Bas reminds readers that despite the extensive Citrix toolset, the basics still matter: a simple NetStat or firewall port check, a Ping for network connectivity, Tracert, Telnet, and a quick-and-dirty manual event-log check across all components that might be involved (Controller, StoreFront, Web Interface, VDA). Sometimes all you need is a simple DOS prompt with no separate install or configuration steps.
