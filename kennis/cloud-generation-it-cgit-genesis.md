# Idea: De Cloud Professionals / CGIT as a cross-unit collective

The origin notes for what became Cloud Generation IT (CGIT). The core move: not a standalone company, but a collective name for 5 to 10 professionals already employed across the business units. 'De Cloud Professionals, onderdeel van... it's all about perception.'

Primary proposition is desktop-from-cloud: AWS and Azure (focused on DaaS plus related services like Office/Microsoft 365), Microsoft Windows Virtual Desktop (to ride as it is announced), in combination with Citrix, and Amazon Workspaces. The pitch to the delivery side: there is still margin in it, it fits most roadmaps, and 'voor ons is een desktop uit de cloud een fluitje van een cent.'

The wrap-around services: DRaaS, backup (BaaS, including specifically for Office 365), archiving, secure data share, data classification, classic Citrix/RDS from the cloud, standalone Office 365, and workspace aggregation (everything from one portal). Plus an existing managed-services arm, so 'alles onder een dak'.

He is candid about the mechanic: 'Zie het een beetje als oude wijn in nieuwe zakken', repackaging and re-presenting what the company already has in house, with a strong marketing story around it. Domain names considered: decloudprofessionals.nl, comegetit, with the CGIT logo chosen by poll.
