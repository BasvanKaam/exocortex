# Windows 10 Multi-User (Azure-only) and ProPlus

Microsoft announced (late 2018) a multi-user variant of Windows 10, a desktop OS that multiple users can use simultaneously (RDS for Windows 10) for the first time. It is available only on Azure, which Bas notes was still too early for many organizations at the time. On Windows 10 Multi-User, ProPlus is allowed and fully supported by Microsoft with no end date. This later became the foundation of Windows Virtual Desktop / Azure Virtual Desktop. Dated 2018-2019 announcement-era note.
