# SCAF Cloud Exit Strategy Template (On Bas's Backlog)

In the "Roadmap En Backlog" section, Bas reveals that while writing he continually generated new ideas and insights — many made it into the book, many did not. He keeps a backlog of 20+ ideas, using the term as it's used in product development.

Among the concrete items he wanted to build but had to defer: a **Cloud Exit strategy template — explicitly as part of the SCAF toolkit** — together with an accompanying questionnaire (vragenlijst). Another deferred topic was security in the context of AI.

He had to draw a line ("ik moest er een keer een einde aan breien") to actually ship the book, noting he already has nearly enough material for a part 2 ("deel 2").

This is a useful pointer: the SCAF (Step-Cloud Adoptie Framework) toolkit is intended to eventually include a Cloud Exit strategy template, even though it isn't fully covered in this edition.
