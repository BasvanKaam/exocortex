# App layering that keeps the base image clean is the right model for AVD

Bas's stance: application delivery and ongoing management is a real, common pain point, he sees a lot of customers struggling with it. The model worth backing decouples apps from the OS so the base image stays clean, supports a wide application catalog (FlexApp One ~90% vs MSIX ~30%), and lets you update a copy and swap packages with no interruption and no agents. "Clean, simple, and fast" is the bar for AVD application management.
