# Ship sensible defaults, because people don't read the manual

A small but telling product-design stance from the VDI Drones 2019 update. Originally users had to run drone.exe once to generate a config file; it was documented, but 'many people forgot to read the manual', and the program crashed badly when no .cfg was present. Lesson Bas and the team applied: ship a default config file so the tool works on first run, and replace a hidden context-menu action with two big obvious start/stop buttons. The framing: community feedback ('a storm of publicity led to the discovery of some bugs') drives the roadmap, and good defaults plus obvious controls beat correct-but-ignored documentation.
