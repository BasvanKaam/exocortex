# Same cloud service, different name per vendor

A durable orientation point from Bas's 2018 cheat sheet: every major cloud (AWS, Azure, Google) offers broadly the same building blocks but uses slightly different naming conventions, which is a frequent source of confusion when moving or comparing between platforms. The four building blocks worth anchoring on are Compute, Networking, Storage, and Databases, what he calls 'the building blocks of (Cloud) life'. The practical takeaway: when learning a second cloud, map by purpose/use-case first, then look up that platform's specific service name, rather than trying a feature-by-feature like-for-like comparison.
