# Where Nerdio adds value on top of native Cloud PC

The framing Bas uses for the Nerdio value proposition on Cloud PC: native Cloud PC trades flexibility for simplicity. Self-service Cloud PC has no ongoing-management portal at all (only the 365 portal to hand out licenses and kick off provisioning); after that, management falls to the end user or a third-party tool. That gap is where Nerdio Manager slots in, the same way it does for AVD, so the two run side by side from a single console.

What Nerdio Manager layers on (both MSP and Enterprise editions):
- Image management for MEM-managed Cloud PC from the same interface as AVD, making image-based deploys, updates, and patching schedulable and automated. (Note: image-based management applies to MEM-managed only, since Cloud PCs are persistent.)
- Auto-provision / autoscale / fine-tune supporting infra (file server or Azure Files) when needed, again MEM-managed only because it shares AVD's networking flexibility.
- (Re)provision machines, provisioning policies (image, network connection, user assignment), multi-tenant management, network connections incl. AD, scripted actions, full auditing.

Nerdio Manager also enables AVD-to-Cloud-PC migration in both directions so each user lands on the right desktop type at the lowest cost.

Bas's recurring positioning line: pick the right technology for the right use-case, with a strong focus on ongoing manageability and the financial side.
