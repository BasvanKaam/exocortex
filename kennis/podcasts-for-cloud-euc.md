# Podcasts as a learning channel for Cloud and EUC

Bas recommends EUC and cloud podcasts as an easy, accessible way to stay current on trends, technologies and best practices - listenable during commuting or exercise without reserving agenda time. Topics range over technologies, tools and updates from big providers (AWS, Azure, Google Cloud) and EUC/cloud innovation. Many feature interviews with experts, IT leaders and industry pioneers offering deep technical insight, plus practical tips on implementation, cost optimisation, security and performance useful for beginners and advanced listeners. They share success stories, foster an innovative mindset, and help build a community of like-minded people, sometimes with associated discussions, meet-ups or events.

The podcast overview he lists includes: The Cloudcast, AWS Podcast, Google Cloud Platform Podcast, Microsoft Cloud Show, Cloud Unfiltered, The Cloud Podcast, CloudSkills.fm, Day Two Cloud, Go Time, Cloud Security Podcast, Cloud Engineering, On Cloud, Screaming in the Cloud, VMware Roundtable, Cloudcast Basics, Cloud Cost Playbook, Cloud Atlas, Dutch Cloud Community Podcasts, IBestuur Podcast, Techzine Talks, De Dataloog Cloud Journeys, Techionista Podcast, CTOcast, Tech Update (BNR), 5 Bytes Podcast, Microsoft Azure Podcast, Amazon AWS Podcast.
