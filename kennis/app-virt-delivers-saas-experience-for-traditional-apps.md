# App virtualization gives traditional apps a SaaS-like experience

Bas's method for handling traditional (Windows) applications in a SaaS-dominated, hybrid environment: use application virtualization so the user gets a SaaS-like experience when launching the app. His framing is that the only thing that counts is how the user experiences the app, the delivery technology underneath is irrelevant to them. This effect is amplified when a (Unified) Workspace aggregation portal brings all application types, desktops and data together, so the user never knows where a resource is actually launched from. The reasoning: rather than locking down the device and restricting the employee, deliver from the cloud onto whatever endpoint makes the user happy, and let aggregation hide the plumbing.
