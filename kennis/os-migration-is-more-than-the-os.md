# OS Migration Is More Than Swapping the OS

Upgrading or switching to a new operating system version has always been a hard undertaking, because far more is involved than just changing the underlying OS: application compatibility, processes, policy, security, and user impact all come along. A common pattern: by the time platform X is delivered and in production, the next version is already at the door.

The servicing-treadmill point: Windows 10's twice-a-year, more-or-less mandatory feature updates made it nearly impossible for many organizations to keep up. Where migrations used to go from Windows XP/7/8 to Windows 10, organizations now effectively migrate from Windows 10 to Windows 10, a near full OS upgrade every time. This is durable thinking about update fatigue and lifecycle management, independent of the specific Windows versions.
