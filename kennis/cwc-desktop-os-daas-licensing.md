# CWC as a near-DaaS workaround for Microsoft desktop-OS licensing

FMA fact Bas highlights: because of Microsoft's licensing restrictions on desktop Operating Systems, it is very hard to build a true DaaS solution based on an actual desktop OS while keeping costs acceptable. With CWC you can host all infrastructural components in the cloud and leverage your own on-premises VDAs, which can be VDI and 100% desktop-OS-based. While not exactly the same, this comes close to a desktop-OS-based DaaS (private cloud) offering.
