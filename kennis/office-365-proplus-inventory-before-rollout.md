# ProPlus pre-rollout inventory checklist

Before adopting ProPlus, inventory and decide on: Windows vs Mac OS; 32 vs 64-bit; single desktop vs multi-user server; existing Office versions and any VBA macros or plug-ins (and whether they survive a newer Office); Visio/Project/Teams (licensed separately, outside the suite); language packs; client minimum requirements; available deployment tools; user count (per-user licensing, ensure enough licenses); internal network capacity (~1.6 GB primary files per user, ~250 MB per language pack); internet access for activation and the 30-day check; required protocol ports; and CDN vs local update sourcing.

Microsoft's Readiness Toolkit scans Word, Excel, PowerPoint, Outlook, Access, Project, Visio and Publisher (back to Office 2003) for add-ins, plug-ins and macros and reports compatibility issues with recommendations. Microsoft advises removing older Office versions first (the ODT can help). Always validate with a pilot group on both deployment and software compatibility before rolling out broadly.
