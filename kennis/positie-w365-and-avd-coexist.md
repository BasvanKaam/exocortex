# Windows 365 and AVD Are Complementary, Not Competing

Bas's stance: Windows 365 and Azure Virtual Desktop go hand-in-hand rather than one replacing the other. If you already run AVD or are considering it, W365 can be "easily leveraged alongside" — same Windows subscription requirement, shared components (VNets, domain join, image deployment), and ideally managed from a single interface.

His argument for why this matters in practice: customers increasingly want both co-existing in the same tenant (persistent per-user Cloud PCs for some, pooled/personal autoscaled AVD for others), and the real win is managing them together — shared image management, shared automation, one help-desk console — rather than treating them as two separate stacks.

The low-risk entry argument reinforces it: W365 is subscription-based with no minimums, so you can try it and, if it doesn't fit, hand the licenses back to Microsoft.
