# Windows 10 Enterprise multi-session performance debate (Ignite 2019)

At Microsoft Ignite 2019 WVD was a hot topic with a flood of announcements. Bas highlighted a performance discussion (from E2EVC, citing Ruben Spruijt / Rex Analytics / Benny Tritsch) claiming "Windows 10 EVD 'MultiUser' beats Windows Server 2019 RDSH" on performance enhancements within Windows 10 Enterprise Multi-Session. How it worked then: Windows 10 Enterprise multi-session was the new WVD-exclusive OS and its performance relative to traditional RDSH was an open, debated topic in the EUC community.
