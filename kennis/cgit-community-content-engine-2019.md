# CGIT community + content engine: events, whitepapers, podcasts, ambassadors

Snapshot (June 2019) of how Cloud Generation IT (CGIT) was being built as a community and content engine:

- A vendor-neutral CGIT event (4 July) with theme, location, and speakers, promoted via a run of blogs.
- A book giveaway launching that weekend in Berlin, with Salomon as one of the sponsors; CGIT stickers in circulation.
- A whitepaper pipeline: 'Implementing and maintaining Office 365 ProPlus' (nearly done, in language review), then 'OOBE / AutoPilot' (with Niels), and 'NEN + MS Cloud plus security'.
- A content-production overhaul: create content, get it done faster, more people involved for editing.
- Podcast strategy: multiple formats discussed, possible guests and topics, collaboration with EUC-digest (ex Login TechCast), exchanging podcast hosts, cross-guesting between Come Get IT and CGIT.
- A NetScaler taskforce wrapping up with several people certifying, to be leveraged for marketing (social media/blogs).

The durable idea: pair a vendor-neutral community event with a steady whitepaper + podcast + blog cadence and an ambassador/cross-promotion network, rather than relying on direct sales.

Dated: specific 2019 events, the Office 365 ProPlus naming, and a NetScaler taskforce make this time-bound.
