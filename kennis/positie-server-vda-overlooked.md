# The Server VDA is the component everyone overlooked

As of December 2015, Bas's framing: ever since XenDesktop 7 integrated XenApp under the FMA, a lot was written about its components, but the Server VDA was almost never mentioned, which surprised him given it was a brand-new component. His angle is to document 'the one that (almost) got away'. This post is part of the FMA Internals Co-Op he ran with Mick Glover (@XDTipster), reflecting his deliberate project to document FMA internals that the wider community had skipped over. He credits Mick for filling in blanks, showing his collaborative, give-credit style.

*Bron: blogpost 'An in-depth look at the Citrix FMA Server VDA… The one that (almost) got away!' (2015-12-16), basvankaam.com.*
