# Office 365 ProPlus versus traditional Office

Framing Bas uses to position the two Office variants for clients. ProPlus is a full Office install (physical or virtual workplace, no permanent internet needed) whose additional services run well ahead of the perpetual variant.

Key distinctions he draws:
- ProPlus bundles additional services (OneDrive storage, Skype minutes) that perpetual Office (2019) lacks.
- Both now use Click-to-Run; from Office 2019 onward it is the only install method.
- ProPlus gets continuous new features plus security updates (weekly/monthly) via the Azure cloud; perpetual Office gets only security updates, no new features, and a new version requires repurchase.
- ProPlus is a subscription (Opex); Office 2019 is a one-off purchase (Capex).
- ProPlus tracks the Windows 10 Semi-Annual Channel; Office 2019 tracks the Long Term Servicing Channel, hence the large feature gap.
- ProPlus activates online per user; Office 2019 uses KMS or MAK.
- ProPlus needs an internet license check every 30 days but no continuous connectivity.
- ProPlus and a regular Office version cannot run side by side.

Note: this is a dated (circa 2019) technical snapshot; Microsoft has since renamed ProPlus to Microsoft 365 Apps and changed channel names.
