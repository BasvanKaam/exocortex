# Global cloud scale: regions, zones, and which continent has no datacenters

Cloud providers (Azure, AWS, Google) have datacenters worldwide, strategically placed across regions and zones so data is fast and reliable wherever users are. A datacenter (in Azure also called an Availability Zone) consists of thousands of racks of systems working together to store data, run applications and deliver services. Spreading data across multiple locations enables faster recovery from disruptions, keeps services available, and puts a datacenter nearby for lower latency.

Nearly every continent has datacenters from the big providers. Bas poses a riddle: which continent does not? His tip is that it has to do with extreme weather conditions (i.e. Antarctica).
