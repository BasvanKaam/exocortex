# Workspace Cloud lacked an on-prem control plane in 2015

How it stood in 2015: Citrix Workspace Cloud was a cloud-hosted control plane (running on / based on ShareFile infrastructure) with customer data kept on-prem. Bas estimated roughly 80-85% of companies would be fine with this model because they retained control over their data. The gap was the lack of an on-premises control plane option, which mattered for regulated organisations (government, financial, medical) that want to control everything end to end. VMware was working on an on-prem control plane equivalent for Enzo at the time.

Durable takeaway underneath the dated specifics: cloud-managed control planes hit a wall with sovereignty-sensitive sectors, which is why on-prem control-plane options keep being demanded.
