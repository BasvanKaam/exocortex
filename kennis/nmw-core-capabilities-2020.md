# Nerdio Manager for WVD core capabilities circa 2020

How it was then: as pitched at IGEL Disrupt 2020, Nerdio Manager for WVD's core feature set was hostpool creation, adding/removing hosts (by hand or via unique built-in Autoscaling), image management (import, update, and use images to update hostpools fully automated and scheduled), FSLogix enablement combined with Azure NetApp Files / Azure Files / a standard file share, and built-in RBAC roles (including an 'end-user' help-desk role). All driven through one GUI, with the explicit goal of 'hiding complexity.'
