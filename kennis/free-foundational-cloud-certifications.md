# Three (Almost) Free Foundational Cloud Certifications

Bas's pointer for people getting started with cloud, or who have worked with (e.g.) Azure a while but haven't certified yet. He collected the free official training material, an extra study resource, and the exam code for each so readers can plan their exam when ready.

- **Microsoft Azure Fundamentals** — exam AZ-900. Official free path via Microsoft Learn; extra study guide on absolute-sharepoint.com.
- **Microsoft 365 Certified Fundamentals** — exam MS-900. Official free path via Microsoft Learn; extra study guide on absolute-sharepoint.com.
- **AWS Foundational, Cloud Practitioner** — exam CLF-C01. Official free Cloud Practitioner Essentials training via AWS.

Dated: the exam codes and Microsoft Learn URLs reflect the late-2010s/2019 certification lineup (CLF-C01 in particular has since been retired/renumbered).
