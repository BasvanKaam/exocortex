# The NMW thesis: automation and hiding complexity

Bas's one-line distillation of what sets Nerdio Manager for WVD apart, used as a session header: "It's all about automation and hiding complexity."

The argument: WVD has a lot happening under the hood, but the admin/MSP should not need specific Azure, PowerShell, or WVD knowledge. NMW exposes everything (tenants/workspaces, hostpool creation, host add/remove, autoscaling, image management, FSLogix + Azure Files / ANF, RBAC roles) through an intuitive GUI, 100% manageable without scripting. Recurring positioning he returns to across his Nerdio content.
