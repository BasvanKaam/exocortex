# SCAF - Step-Cloud Adoptie Framework

Bas's own structured, phased cloud-adoption framework, defined in his book 'Cloud Mastery'. It guides organizations through a staged move to the cloud built on four pillars: strategy (strategie), insight (inzicht), execution (uitvoering), and adoption (adoptie). Positioned as his alternative/companion to vendor frameworks like the Microsoft Cloud Adoption Framework and the AWS adoption framework. This is BvK IP, not commodity content.

*Bron: Inside Citrix (2016), 'Hoofdstuk 14 - Begrippenlijst (Cloud Mastery)'.*
