# Byte Squared brought native iOS Office editing into the Citrix Worx stack

How it worked then (2013): Citrix acquired Byte Squared, whose Office suite (Doc, Sheet, Slide) let users create, view and edit Word/Excel/PowerPoint files natively on iOS (iPad/iPhone). Citrix planned to fold this into an 'Office for Citrix Worx' all-in-one app.

Before this, the workflow to edit an Office document on a XenMobile-managed device was: open the .doc/.docx from ShareFile, which triggered an 'Open with' dialog launching Microsoft Word published from XenApp inside the secure MDX container. The Byte Squared route would let users edit Office files natively on the device without needing XenApp or ShareFile in the loop, inside the MDX/Worx secure container. A noted limitation at the time: no Android support, so Android users had to keep using the ShareFile-plus-XenApp approach. The competitive angle was displacing Good Dynamics (Office Pro for Good).
