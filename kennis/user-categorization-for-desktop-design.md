# Categorize users before choosing a desktop model

A durable design method Bas pushes: don't pick a delivery model first, segment your users first.

- Task workers: small app set but handle critical data; Hosted VDI or Hosted Shared (maybe DaaS) fits.
- Road warriors: need desktop/apps from anywhere; a local VM (e.g. XenClient) may fit, with offline/cached apps.
- Office-bound staff (e.g. HR): low flexibility need; Hosted Shared Desktops or streamed/published apps suffice.

Or classify users as light/medium/heavy. The point: involve users from the start, inventory their daily routines, because user acceptance makes or breaks the project. Don't pick VDI just because it 'sounds sexy'. Inventory exceptions and address them so the majority benefits, rather than choosing a one-size solution that doubles or triples TCO. KISS: Keep It Simple Stupid.
