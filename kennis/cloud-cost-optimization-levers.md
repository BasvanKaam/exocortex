# Cloud cost-optimization levers

Bas's checklist of where to find cloud savings, grouped by Resources, Licenses, Network and Storage:

- Free subscriptions / cloud-native services
- License programs and Reserved Instances
- Prices per Region; Spot Instances
- TCO calculators; autoscaling
- Resource tagging; storage tiering
- Advisory reports; archive storage
- Billing alarms; right-sizing (correct scaling)

The through-line: combine commercial levers (reserved/spot, region pricing, license programs) with technical levers (autoscaling, tiering, right-sizing) and governance (tagging, billing alarms, advisory reports) to control TCO.
