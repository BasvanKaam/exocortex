# Position: Cloud Is a Strategic Derivative, Not a Goal in Itself

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The framework holds that cloud is not an end in itself but an enabler for becoming a Modern Enterprise. No normal organization has "provide cloud services" as a strategic objective, so IT and cloud strategy should be derived top-down from the Digital Strategy, which itself serves business transformation.

The corollary stance: the chosen business strategy (for example Operational Excellence versus Product Leadership) dictates IT needs, so there is no one-size-fits-all cloud approach. He pushes against treating cloud adoption as a technology project, insisting it be anchored in strategic business goals.
