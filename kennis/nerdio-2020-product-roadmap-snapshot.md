# Nerdio Manager for WVD roadmap as of mid-2020

How it was then: in June 2020 Bas listed coming Nerdio Manager for WVD features he'd had a sneak peek at: Azure WVD cost modeling and auto-scale savings reporting, deployment automation for Azure NetApp Files and Azure Files with AD integration, Ephemeral OS disks, Desktop Image versioning, and Role-based access control. Useful as a timestamp of where NMW's feature set stood and where it was headed in 2020. Most of these later shipped as standard capabilities.
