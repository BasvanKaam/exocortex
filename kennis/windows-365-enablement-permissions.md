# Why Windows 365 enablement needs Global Admin (org consent)

From Bas's review: enabling Windows 365 in Nerdio requires Global Admin, and this consistently raises permission questions. His point: explain the why. The Global Admin requirement is driven by the consent that must be given at the organizational level, that is the actual reason, not an arbitrary high-privilege ask. Teaching the consent rationale up front removes a lot of the recurring confusion and FUD around these permissions.
