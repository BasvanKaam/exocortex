# WCGF Domain: Platform Design, Service and Tooling Integration

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

A WCGF operation domain on designing the cloud platform and integrating services and tooling. Moving to cloud changes the interfaces between services and processes; true cloud services integrate via APIs that move data, create automated triggers, and standardize and automate deployments.

Realizing the vision of a data-driven, agile, innovative organization requires higher process maturity and extensive automation, which is why proper platform design and tooling integration matter. The design and its integrations must be fully understood and supported by the business, so IT must not go at it alone.

The CCoE's Plan-and-Build activity is to design a platform with new tooling for: basic automation (monitoring, provisioning, configuration), ITSM tooling (monitoring, events, incidents), continuity (DR and backup), security systems integration, and CI/CD integration. Integration designs are also needed for processes such as Financial Management, Reporting, Application Management, Security Management, and Identity and Access Management (IAM). The domain to-do is to enrich and update architecture documentation.
