# ProfileUnity feature set and all-in-one model (2017)

How it stood then. Liquidware ProfileUnity is positioned as an all-in-one User Environment / Workspace Manager with no modules and no bronze/silver/gold tiers, everything in one package. Key characteristics: no extra infrastructure or licenses (built-in web server and database), ready for first use within ~30 minutes, highly available by leveraging existing infrastructure. Capabilities include Profile Portability (universal cross-OS-version profiles), easy recovery of user persona data (stored in Windows-native format), background migration of user-authored data before invoking folder redirection, Office 365 Outlook caching/indexing via ProfileDisk, Active Directory/GPO import and management, machine (HKLM) policy management, integrated FlexApp application layering, Elevation and Application Rights Management, a lightweight client in direct or cached mode (delivered via GPO, no per-desktop install), a Context-Aware filter engine with 300+ conditions, Trigger Points (pre/post-login action-based updates, e.g. location-based printing), and environment variable management.
