# Citrix proximity printing

With the Universal Print Server, you can configure proximity printing, based on session (network) printers. Session printer policies are filtered on IP address or subnet, so specific printers within the same range are assigned based on the user's IP/subnet, giving users the closest printer (when configured correctly).

Proximity printing cannot be used without the Universal Print Server. Session printers are network printers assigned/mapped to specific users or groups; since they generate network traffic, use them only on faster networks.
