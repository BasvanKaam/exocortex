# Google Cloud cost management and optimisation tools

Reference list of Google Cloud Platform (GCP) cost-management and optimisation tooling cited by Bas.

**Analysis & monitoring**: Google Cloud Billing Reports (spend per project/service/region); Cost Table Reports (detailed per-resource breakdown); Recommender Tool (automatic optimisation recommendations); GCP Cloud Monitoring (real-time usage/cost with dashboards and alerts); GCP Cost Breakdown Reports (per service and team).

**Reduction & optimisation**: tagging and labels (e.g. Team=AI, Env=Test); folder & project structuring for cost segmentation; Committed Use Discounts (CUDs); Preemptible VMs (temporary VMs with discounts up to 80% for non-critical workloads); Storage Lifecycle Management; Google Cloud Recommender for IAM (find over-privileged accounts, better access management).

**Budgeting & automation**: Budgets & Alerts; Cloud Scheduler (scheduled shutdowns); BigQuery cost controls (query limits); Sustained Use Discounts (SUDs, automatic discounts for continuous VM use without reservations); GKE Autopilot (optimised Kubernetes, charges only for used resources).
