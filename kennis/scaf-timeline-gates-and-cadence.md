# SCAF timeline: phase durations, decision gates, and reporting cadence

The Masterclass plots SCAF on a timeline to show pacing and control points, which the book's phase descriptions do not make explicit:

- Phases run Project initiation -> Strategy -> Insight (Inzicht) -> Execution (Uitvoering) -> Adoption, each spanning weeks; the full track runs into months to roughly a year.
- Decision gates sit between phases: the Business-case gate and a Go/No-Go gate govern whether the program proceeds, ending with a final report (Eindrapportage).
- Progress reporting and measuring (Voortgang, Rapportage, Meten) run continuously alongside the phases, not just at the end.

The teaching point is that durations vary from weeks to months and that go/no-go control is built into the timeline, so cloud adoption is gated and measured rather than a single push.
