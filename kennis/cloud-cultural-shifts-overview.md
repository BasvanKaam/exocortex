# Cloud Cultural Shifts: DevOps, Automation, New Roles

The cultural shifts Bas lists when moving to the cloud:
- **DevOps/agile and self-steering teams** — faster reaction to change, shorter dev cycles, better IT-business collaboration. Cloud supports CI/CD (continuous integration and delivery). DevOps merges previously siloed development, test, and operations roles into self-steering teams responsible for the whole process from development to deployment and maintenance.
- **Changed internal processes** — traditional processes give way to dynamic, iterative workflows. Reflect each iteration: what went well, what didn't, what did we learn, how do we use it next time.
- **More automation** — automating repetitive tasks (scaling infrastructure, assigning users to resources, managing security configs) frees teams for innovation and strategy.
- **Capex becomes Opex** — shift from large upfront hardware investments to usage-based, variable costs; can trigger resistance from departments used to fixed-budget IT.
- **New ways of IT-business collaboration** — IT becomes a strategic partner, requiring soft skills to work with non-technical colleagues.
- **Adaptability** — culture must allow experimentation and innovation, correcting mistakes fast.
- **Changed roles** — new roles emerge such as cloud architects, DevOps specialists, and cloud security experts.
