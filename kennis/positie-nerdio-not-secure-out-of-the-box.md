# Nerdio Is Not Secure Out of the Box, So Always Harden

Bas's position: a default Nerdio deployment is not securely configured, and because locking resources down (firewalls, private endpoints, vNet integration) costs nothing, there is no excuse not to do it. He believes the field should always advise and actively help customers harden their deployment rather than leaving it at defaults. The harder path (private endpoints keeping traffic inside the customer's Azure tenant) is explicitly the better one.
