# AVD - The Only Cloud Service That Runs Windows Client Multi-User

Before AVD (then WVD) was introduced, a multi-user environment was always based on a Windows Server operating system. With the arrival of AVD this changed: Windows 10, 11 and so on — the same OS we all use at home — can now be used by multiple users simultaneously as part of a multi-user environment, automatically giving users the look & feel of a 'home' OS.

Important: AVD is the ONLY cloud service that offers this capability and may deploy Windows 10/11 etc. this way. The Server OS remains optional.
