# Virtualization is a part of cloud, not the same thing

A durable distinction Bas keeps repeating: people confuse cloud and virtualization. Virtualization is just one of the technologies that make up cloud computing.

Virtualization is the main enabling technology: it turns the rigid physical infrastructure into a soft, easy-to-manage component, providing the agility to speed up IT operations and cutting cost by raising infrastructure utilization. Autonomic / automated provisioning then lets users get resources on demand, reducing human error. Cloud's goal is to let users benefit from these technologies without deep expertise in each, so they can focus on their core business.
