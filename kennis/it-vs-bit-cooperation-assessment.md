# IT-vs-BIT cooperation scoring assessment

A signature interactive instrument Bas uses in the workshop. It is a set of statements that each yield an 'IT' outcome and a 'BIT' (Business-IT) outcome; based on the answers the audience earns a score. The point of the exercise is to surface how well IT and 'the business' actually work together, and to land the argument that the answer should be Business-IT, not IT alone. He frames it as 'a nice one for the audience' - a participatory diagnostic that makes the IT-business gap concrete rather than abstract.
