# Webinar Curriculum: The Onboarding Arc

A reusable way to structure a product-training webinar series for a community: sequence sessions as an onboarding arc rather than isolated topics. Each session opens with a short recap of the prior one, then builds on it. The arc moves from "get started / install and setup" to "core feature in detail (autoscaling)" to "adjacent capability (image management)" to "day-two operations (overall management, users, roles)" to "observability and lifecycle (monitoring, logs, updates)" and finally "commercial mechanics (licensing, counting, invoicing)."

The pattern: every session starts with "Short recap," so latecomers can join any session and learners who attend in sequence get reinforcement. This is a deliberate spaced-repetition scaffold baked into a live-session calendar.

Reusable session-design questions Bas uses to frame any feature webinar: What is it? How does it work? What are the advantages / cost savings? How do you configure it for each scenario? This four-beat structure (what / how / why it matters / how to do it) is his default explainer shape.
