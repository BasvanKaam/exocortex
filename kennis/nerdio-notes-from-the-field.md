# Notes from the field: Bas's Nerdio lesson series

"Notes from the field" is a series of Nerdio University lessons written by Bas as Principal Learning Architect, to be made publicly available. Each lesson takes one Nerdio Manager for Enterprise capability and teaches it the way a help desk or platform team actually meets it: what it is for, how to plan it, how to use it, and what goes wrong. Every lesson closes with a conclusion and a knowledge check (drag and drop, matching pairs, branching scenario, select all that apply, put in order).

The notes in this brain hold the essence of each lesson, not the full text. The source documents are Word files (.docx) Bas authored.

## Lessons in the series

### Console Connect (three-part track)
Read in this order; the third lesson lists the first two as prerequisites.

1. [Plan and scope Console Connect for help desk teams](console-connect-plan-and-scope-help-desk.md): Console Connect versus session shadowing, regions, capacity and licensing, a custom RBAC role, and the current limitations.
2. [Use Console Connect for end-user and session host support](console-connect-end-user-and-session-host-support.md): Interactive versus Toolbox sessions, connecting to every endpoint type, in-session tools, and troubleshooting by agent status.
3. [Console Connect agent deployment and the connection path](console-connect-agent-deployment-connection-path.md): how the agent reaches each device type, its footprint, how to verify it, and the five-step connection path.

## How the series is built
- Lesson pattern: problem-first intro, prerequisites, H2 sections per task, Note / Tip / Important callouts, a realistic scenario per concept, a conclusion, and two or three knowledge checks.
- Cross-links between lessons point to Nerdio University titles, so each lesson stands alone but the track reads as one.
- Follows the Nerdio style guide and content guard (American English, Nerdio terminology, UI names in bold in the source).
