# FSLogix benefits for WVD (and on-premises)

The FSLogix advantages Bas highlighted for WVD, explicitly noting they also apply on-premises (2019 state):

- Outlook caching plus Windows Search support.
- OneDrive for Business support, including Files On-Demand; a per-machine version of OneDrive now available, with a per-machine version of Teams to follow later.
- Native SharePoint support in Windows Explorer.
- Office 365 ProPlus computer-activation license roaming.
- Skype for Business GAL caching.
- Microsoft Teams support for virtual desktops.
- Cloud Cache: automatic storage failover and globally-redundant disaster recovery for profiles.
- Application masking.

The framing he stresses: these are not WVD-only benefits — the same FSLogix value lands on existing on-premises RDS/VDI estates too.
