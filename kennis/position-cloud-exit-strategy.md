# Have a cloud exit strategy; lock-in and weak portability are real

Bas's stance: because there are few true standards in cloud (APIs are the closest thing) and vendor lock-in is very real, having a cloud exit strategy is important. Providers define internal standards and run initiatives to ease hybrid/multicloud, but the lack of genuine portability remains a primary reason to plan for the exit before you commit.
