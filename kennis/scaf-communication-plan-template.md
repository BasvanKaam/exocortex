# SCAF Communication Plan Template

A Cloud Masterclass deliverable that structures stakeholder communication during a cloud transition, supporting the Adoptie / Communicatie stages of SCAF. It is deliberately delivered empty rather than pre-filled, because every project differs; all text fields are adjustable.

The plan is built from six elements:

1. **Doel (goal)** - what is the purpose of the message? E.g. informing about cloud-transition progress, or communicating when there are problems (for example as part of a Disaster Recovery plan).
2. **Situatieanalyse** - what does the current (project) environment look like?
3. **Publiek (audience)** - which target group(s) is being communicated to?
4. **Bericht / boodschap (message)** - what must be communicated, at what language level and tone? A pre-defined message can be copied and pasted in.
5. **Communicatiemedium** - via which media channel is the message delivered?
6. **Tijdschema (schedule)** - when is the message first sent and who is responsible?

It is accompanied by a contacts table (name or group, email, phone). Bas suggests optionally adding a priority column to capture who must be informed first in a given scenario.
