# XenApp 7.5 returns as a brand on FMA, not a return of IMA

How it worked then (early 2014): after XenApp had been folded into XenDesktop 7 (on the FlexCast Management Architecture, FMA), Citrix announced XenApp 7.5 "back by popular demand." The key point: this is largely a branding/marketing move, not a return of the old IMA architecture.

- Still FMA. IMA stays dead and buried, so still no zones, data collectors or Local Host Cache as in classic XenApp.
- XenApp 7.5 and XenDesktop 7.5 share the same infrastructure, management console (Studio) and monitoring (Director with EdgeSight), as effectively one product, but Citrix now offers them as separately badged products for those who prefer the separation.
- Notable capabilities announced: **Hybrid Cloud Provisioning** (provision app/desktop workloads to public/private cloud and on-prem from one console via MCS), full **App DNA** with P2V app migration (for Platinum), and the claim of hosting **5 generations of Windows applications** from one infrastructure.
- **WebInterface support returned** temporarily, so customers did not have to rush to StoreFront (supported until around August 2016, near Server 2008 R2 end of life).
