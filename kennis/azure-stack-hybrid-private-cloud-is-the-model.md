# Azure Stack / Hybrid-Private Cloud Is the Model for the Next 5-10 Years

Bas takes a clear stance: the hybrid (private) cloud / on-premises model, embodied by Microsoft Azure Stack, will be *the* model for the next 5 to 10 years. His argument: Microsoft recognized the rise of hybrid-private and on-premises environments and is betting big on Azure Stack, logically so, because the model delivers many (not all) cloud-computing benefits without going all-in on "the cloud" for your base infrastructure and data, while keeping it on-premises in your own datacenter, which also benefits speed and user experience. Whatever the driver (gut feeling, legislation, technical restrictions), he asserts the leading analysts agree this is where things are heading.

Note: this is a time-bound prediction (circa 2017) and worth reading as a position-in-its-moment rather than a current claim.
