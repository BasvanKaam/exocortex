# SCAF insight-pillar intake workshop questions

The intake question set for the SCAF insight (inventory) workshop. Bas works toward a complete inventory of all applications in use and of all physical/virtual systems, network and security components, asking how best to approach each. He then probes: which overviews already exist (applications, licenses, datasets, security policy, governance, processes) and where to find them; whether they can get access to the systems, possibly supervised; whether inventory/monitoring software is in use and whether he may deploy his own; what other management/process tooling is used; the current knowledge level around cloud and how it is maintained; and which teams are active (not limited to technical). Supporting templates in this phase: a per-application classification table (current type, core yes/no, dependencies, priority/impact, first cloud impression, migration strategy via the 6 R's, modernize yes/no/investigate, rationale) owned by the CISO; a network/dependency questionnaire (latency sensitivity, data location, data volumes, storage type, hardware/OS/app dependencies, multi-user certification, security requirements); a security baseline checklist; and a process-mapping question set.
