# Citrix's serial renaming: TaaS to Insight Services to Smart Check

A lineage worth keeping for anyone confused by Citrix naming: Tools as a Service (TaaS) was renamed Citrix Insight Services, and Smart Check builds on those services with the same kind of proactive checks. Smart Check itself was briefly named Smart Update before launch, and it sits inside the Smart Tools portfolio, which was the new name for Lifecycle Management Services. Smart Check and Insight Services could run alongside each other; Smart Check only covered XenApp/XenDesktop while Insight Services covered almost the whole Citrix portfolio, so Bas speculated Smart Check would eventually replace Insight Services but not soon. A concrete case study of Citrix's habit of renaming the same capability repeatedly.
