# Greenfield onboarding is a utopia; plan for existing profiles and data

His framing of workspace transitions: onboarding genuinely new users is easy because they have no history, no profiles, no documents or data, but he calls that a 'utopia', it is unlikely to happen. In almost every real transition you already have some VDI/RDSH or similar workspace in place, so users arrive with existing user profiles and data that must be harvested and migrated. Tooling (in this post, Liquidware ProfileUnity) is positioned to harvest current profiles and application data and let users co-exist and move across physical, virtual, RDS and mixed Windows OS environments.

A durable migration truth: design for brownfield, not greenfield.
