# Cloud Masterclass: the curriculum Bas teaches

A two-day masterclass that moves from the earliest origins to the cloud of today: a slice of history, the underlying principles and technologies, the cloud economy, and the most eye-catching trends. SCAF runs as the red thread throughout.

Learning outcomes Bas frames the course around — after it a participant can:
- Take their own or a client's organization toward the cloud using a solid framework.
- Recognize what changes inside an organization when it adopts cloud services.
- Explain what cloud governance is and how to start with it.
- Explain what a cloud exit strategy is, give multiple reasons why it matters, and how to begin one.
- Judge which cloud (delivery) model fits which situation best.
- Assemble a high-level financial business case and name the variables involved.
- Name the primary differences between the various cloud providers.

And is familiar with: basic and advanced cloud concepts; cloud history and trivia; the user impact of cloud; the technology behind IaaS, PaaS, SaaS and DaaS; the cloud architectures of the three largest providers; the financial impact of cloud; and the IT communities and how to benefit from them.

This curriculum is a durable map of how Bas structures cloud education: history -> principles -> economics -> governance -> exit -> delivery models -> provider comparison.
