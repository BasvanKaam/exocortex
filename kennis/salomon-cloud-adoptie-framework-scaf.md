# SCAF: Salomon Cloud Adoptie Framework

SCAF is Salomon's own (vendor-independent) cloud adoption framework, used as the spine of the two-day Cloud Masterclass. It walks an organization step by step from its current state to cloud-based technologies, services and products.

Design intent:
- Pragmatic and easy to oversee, deliberately scalable to both very small and very large organizations.
- Vendor-independent: not tied to one hyperscaler, so it can compare and span AWS, Azure and GCP.
- Positioned as the practical, reusable path a consultant or internal team follows to take 'your own organization, or that of your client' to the cloud.

This is Bas's proposition for structuring a cloud migration as a guided journey rather than an ad-hoc lift-and-shift.
