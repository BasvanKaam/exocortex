# Bas's questions before choosing a layering solution

Before implementing any application-layering solution, Bas offers a checklist of basic questions to ask yourself (or out loud) about the platform you support:

- Is it Citrix XenApp/XenDesktop, VMware Horizon/View, or plain Microsoft RDSH you want to support?
- Which hypervisors are supported (your options may be limited by vendor)?
- Is there a steep learning curve?
- Does it work for persistent as well as non-persistent?
- Can you assign layers to users, machines, or both?
- Does it support both VHD and VMDK?
- Can you assign layers to virtual as well as physical machines?
- What else is in the vendor's portfolio that might combine well with layering?
- Do they offer a persistent personal data / app disk solution, and would you want it?
- A user-profile solution (also layering-based) perhaps?
