# Cloud is not the answer to everything, but baseline knowledge is non-negotiable

His stance: the demand for and interest in cloud services, technologies, and developments can no longer be ignored, if anyone was still ignoring it. But that does not make cloud the answer to everything. To form any opinion on it, you need at least baseline knowledge of the different cloud solutions and platforms. The argument is anti-hype and pro-literacy at the same time: don't treat cloud as a silver bullet, but don't stay ignorant of it either.

Verbatim: "Betekend dat, dat Cloud het antwoord op alles is? Nee, natuurlijk niet. Maar, om daar 'iets' van te vinden is basiskennis (op z'n minst) van de verschillende Cloud oplossingen en platformen wel gewenst."
