# Three foundational cloud certs (2019)

How it stood in 2019: three entry-level cloud certifications with free official training material (only the exam itself costs money).

- Microsoft Azure Fundamentals: exam AZ-900
- Microsoft 365 Certified Fundamentals: exam MS-900
- AWS Foundational, Cloud Practitioner: exam CLF-C01

Bas pointed readers to the free Microsoft Learn paths plus Vlad Catrinescu's extended study guides for the Microsoft exams.
