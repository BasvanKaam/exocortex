# Cloud Financial Management: Role Demarcation

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

Demarcation of responsibilities in the financial management domain:
- Product Owner creates a Cloud Service Budget Plan.
- Financial Management monitors monthly cloud spend (deliberately not automated immediately).
- Service Portfolio Manager is ultimately responsible for the P&L of the services.

The CCoE's role is advisory and enabling: it advises on cloud purchasing and contracting processes, ensures the platform can deliver the (meta)data, and presents that data in useful dashboards and reports including recommendations for resource optimization. The CCoE also determines a best-fit consumption model based on historical data, manages service limits, and tunes capacity to workload.

Domain to-do: configure budgets, reports and dashboards for all stakeholders; build awareness of the post-transformation budgetary workings; create transparency in cloud resource cost per business unit/stakeholder.
