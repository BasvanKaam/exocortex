# Match the depth of the financial model to its purpose

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The framework holds that there is no single correct level of detail for a cloud business case: the required depth depends entirely on the purpose of the analysis. Infrastructure-oriented organizations may need to dig to storage and memory level; a SaaS-uptake strategy makes that depth wasteful.

The stance carries a warning he repeats: it is very tempting to analyze ever more deeply, and you must avoid the situation where analysis leads to delay. Consolidate into layers, zoom in only when necessary, and let the question you are answering, not the availability of data, set the resolution.
