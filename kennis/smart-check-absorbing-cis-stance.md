# Smart Check as the future single Citrix diagnostics tool

Writing in mid-2017 after a briefing with the Smart Tools/Insight Services PM (Mathew Varghese), Bas framed Smart Check as the consolidation point: 'the idea is to build all of CIS's capabilities into Smart Check going forward,' with broader product support (StoreFront, PVS, NetScaler, XenServer) on the roadmap. He was enthusiastic about the revamped Scout 3.0 (new UI and backend, no machine-count limits, Logman.exe replacing CDF control, schedulable uploads viewable in Smart Check) and about browser-based custom checks needing no software install. A clearly pro-tooling, proactive-monitoring stance, with credit explicitly handed to the Citrix PM for sharing the demo.

*Bron: blogpost 'Heads up! Citrix Smart Check introduces diagnostics uploads and custom checks and alerts - deep dive (and video) included' (2017-07-31), basvankaam.com.*
