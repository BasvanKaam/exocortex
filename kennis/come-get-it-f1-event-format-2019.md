# Come Get IT F1 Event Format (4 July 2019)

The second Come Get IT event used a single strong theme to tie technical sessions together: Formula 1. The pitch is that IT and F1 have far more in common than people think (speed, data, marginal gains), and that hook frames otherwise dry infrastructure topics.

Speaker line-up as a template for theme-driven curation:
- Nutanix Sr. System Engineer (Bart Groot Zevert) on Web-Scale Hyperconverged behind the Williams Racing F1 team: fast data access and cost savings, a behind-the-scenes look.
- ITQ Technical Marketing Manager (Johan van Amersfoort) on an F1 simulator built purely on vGPU/VMware technology.
- Veeam on data protection / backup for physical and virtual workloads, on-prem and cloud, across most OSes and hypervisors (including Nutanix AHV), with the framing of when to use which product.

The takeaway as a reusable method: pick a vivid, accessible theme, then recruit vendor speakers who can map their tech onto it. The theme does the marketing; the sessions deliver the substance.
