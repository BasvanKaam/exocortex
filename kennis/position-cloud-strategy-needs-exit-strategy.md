# A Cloud Strategy without a reversibility plan is incomplete

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

the framework builds reversibility into the definition of a good Cloud Strategy: it must contain an Exit Strategy. A cloud strategy is not just about getting in; planning how to get back out is a first-class requirement, not an afterthought. This puts reversibility and avoidance of one-way lock-in at the heart of strategy rather than treating it as a niche concern.
