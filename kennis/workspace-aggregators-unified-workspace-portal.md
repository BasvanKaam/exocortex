# Workspace aggregators and the Unified Workspace Portal

In his paper Bas describes workspace aggregators: platforms designed to simplify both the end-user's work and the IT department's job by aggregating all application types — web, mobile, SaaS, Windows apps, desktops and data — into a single web portal.

Typically they can run an RDSH (RDS-protocol) based solution in the background, quickly standing up a server farm (on-prem or cloud) to host traditional Windows apps, offered as published applications or shared desktops — exactly as has been done for the past twenty years. To the end-user it looks like a SaaS variant, while behind the scenes it's still traditional file, print and application systems.

Surveys show strongly rising interest. On the question of interest in a "Unified Workspace Portal" (van Kaam & Brinkhoff 2019), 70.5% answered yes and 20.5% found it at least worth investigating. From EUC State of the Union 2019 (Spruijt, Plettenberg & Brinkhoff), of 580 participants 39.94% said it's something they're interested in and investigating, while 21.04% are introducing or already using one.

Bas's framing: this is again an example of how traditional IT solutions get kept alive and, when it comes to cloud, strongly slow things down.
