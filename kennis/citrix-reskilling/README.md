# Citrix Reskilling (project hub)

Projectmap voor de Citrix Reskill course: 16 modules die alles wat een on-premises Citrix-admin weet mappen naar Azure Virtual Desktop en Windows 365, met Nerdio daarbovenop, plus een gratis Nerdio-installatie voor de hands-on (werknaam: Reskill Edition). Alles over dit project komt in deze map, dit bestand is het startpunt.

Uitzondering op de Nerdio-regel: dit brein staat in een afgeschermde GitHub-omgeving waar alleen Bas bij kan, dus werk aan dit project mag hier staan. Wel alleen publieke informatie, geen Nerdio-IP, geen interne cijfers, geen roadmap. Zie [Projectmappen voor Nerdio-werk](../../beslissingen/projectmappen-nerdio-werk.md).
