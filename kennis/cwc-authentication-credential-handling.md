# CWC authentication and credential handling security

Security facts for the CWC offering:
- An administrator authenticates to CWC via the Citrix online sign-on system; a one-time signed JSON Web Token is generated, granting access to the Apps and Desktops service.
- User credentials are encrypted by the Cloud Connector using AES-256 plus a random one-time key generated for each launch. That key is forwarded to Citrix Receiver (it never goes into the cloud) and passed to the VDA to decrypt the user password at session launch, creating a single sign-on experience.
- When Machine Creation Services creates machine accounts in the customer's AD through the Cloud Connector, the administrator is prompted for each operation, because the Cloud Connector's machine account has only read permissions in Active Directory.
- Hypervisor passwords for authentication are generated by the administrator, encrypted, and stored in the cloud-based SQL database.
