# NIST vs ISO as security reference frameworks

NIST (National Institute of Standards and Technology) is a US organization that develops guidelines and standards for cybersecurity, used as a reference framework especially in the US (government and businesses wanting detailed, practical guidance). A well-known example is the NIST Cybersecurity Framework, which helps identify, manage and reduce risks. NIST offers no recognized certifications — it provides a framework, guidelines and reference models.

ISO (International Organization for Standardization) develops various security standards; in Europe ISO guidelines are regularly applied and seen as the standard for security. ISO 27001 helps companies set up an Information Security Management System (ISMS) and is certifiable.

**Bas's TIP:** Use these standards as a reference! Both offer valuable frameworks to raise security to a higher level — NIST more in the US, ISO more in Europe. For many companies both are too coarse to fully implement or certify against (e.g. ISO 27001), but they serve as excellent reference frameworks. Bas considers NIST, though American, well worth studying in depth.
