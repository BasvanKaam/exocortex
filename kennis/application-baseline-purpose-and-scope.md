# Application Baseline: purpose and scope

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The Application Baseline is a high-level analysis of the current application landscape. It determines the span of governance controls and the scope for cloud migrations. It is positioned as an essential step in the cloud strategy: you cannot govern an IT environment, or cloud migrations in particular, without first understanding the scope and complexity of the application landscape.

The baseline should provide insight into:
- Which (bundles of) applications are part of the estate.
- Which provide competitive advantage (commodity vs competitive).
- Which are mission critical.
- Lifecycle status of each (bundle of) application.
- Relationships between applications and dependence on middleware.
- Underlying infrastructure components and footprint.
- Privacy and CIA classification (Confidentiality, Integrity, Availability).
- Which applications show potential for cloud, and the most important applications per business unit.

Understanding which applications are competitive and which support mission-critical processes lets you prioritize and classify the tactical cloud migrations. A common strategic priority is to relieve IT Operations from maintaining infrastructure for commodity applications.

Part of the Weolcan Cloud Governance Framework (WCGF), Migration section. Feeds the Migration Roadmap and connects to Cloud Placement Decisions and the Financial Baseline.
