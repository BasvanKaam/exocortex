# XenApp 7.6 brought back the IMA features people missed

How it worked then (7.6, Sept 2014): built on Citrix's third-generation FMA, deployable on-premises, in the cloud, or hybrid. Key returning/new features:

- Application Pre-launch and Session Lingering returned (lost in the IMA-to-FMA transition).
- Unauthenticated (anonymous) users for server-OS Delivery Groups, useful for kiosks.
- Connection Leasing introduced to replace IMA's Local Host Cache (a supplement, not an equivalent).
- GPU-based DirectX/2D rendering, Lync 2013 optimization, USB 3.0 redirection.
- PVS 7.1 cache-in-RAM with spill-over to disk to cut IOPS (license-dependent).
- FIPS compliance and Common Criteria.
- Application folders in Studio; clipboard content filtering with directional control.
- XenApp 6.5 migration tooling to move from a 6.5 farm to a 7.6 Site.
