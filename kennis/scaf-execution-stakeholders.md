# SCAF Execution Phase Stakeholders

For the Execution phase Bas again needs technical 'audience': the (technical) application administrator or application owners, the DBA, network and system administrators, and the security officer. Additional input may come from an IT partner, software suppliers or others.

When composing teams and assigning responsibilities, IT management comes back into play. On the financial side the CFO or finance lead joins, and ultimately approval must come from the board and/or directors (CEO, CFO, CTO, CIO).
