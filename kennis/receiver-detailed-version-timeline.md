# Citrix Receiver / ICA Client detailed version timeline

- ICA Client software v4.0, September 1998 (the first release; the ICA protocol, Citrix Multiuser, WinView and WinFrame came earlier). Contained Program Neighborhood, PNAgent and Web install packages.
- v11.0, June 2008: renamed Citrix Plug-in for hosted applications (Web Plug-in), same packages.
- v11.2, May 2009 (Citrix Synergy): Citrix Receiver 1.0 officially released with the Merchandising Server.
- v12.0, March 2010: renamed Citrix Online Plug-in.
- v13.0, August 2011: officially renamed Citrix Receiver (version 3.0). Receiver 3.0 split into Receiver Updater and Receiver Inside; Receiver Inside integrated into the Online Plug-in to form Citrix Receiver Enterprise (up to v3.4).
- v4.0, June 2013: renamed Citrix Receiver for Windows (current name).
- Receiver Updater + Merchandising Server reached EOL August 2015. Receiver Updater auto-installed/updated/restarted Receiver without user interaction.
- Receiver Enterprise 3.2-3.4 still included the original PNAgent (Legacy PNA). As of v4.0 PNAgent was removed, ending the Desktop Lock feature.
- Receiver v4.2 reintroduced Desktop Lock as Receiver Desktop Lock.
- Receiver v4.4 launched December 2015 (most recent at time of writing).

Note: there are separate version-numbering schemes for the ICA Client software and the Citrix Receiver.
