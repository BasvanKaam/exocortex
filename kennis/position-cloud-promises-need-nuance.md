# Position: the original cloud promises must be put up for debate, not taken at face value

Bas deliberately opens by writing out the NIST definition plus the original cloud 'promise', then immediately challenges it. His stance: the famous promises are far more nuanced than people assume and depend on many factors.

- 'Cheaper' - is it really? It depends; a lot of dependencies.
- 'Infinite scalability' - there are genuine limits.
- 'Standards' - largely absent; standardisation exists only within a single cloud, not across.

The pedagogical position is that a cloud workshop should start by puncturing the marketing, because the unmeasurable, hidden variables (and these same promises) come back to bite people in the economics later. He treats myth-busting as the entry point to honest cloud advice.
