# Windows 10 was never the promised 'One OS to rule them all'

In this Nov 2017 post Bas pushes back on Microsoft's Windows 10 marketing. Microsoft 'shouted from the rooftops' that Windows 10 would be the last Windows and that we'd never again worry about new desktop OS versions, but Bas argues appearances deceive: under the hood plenty changes between feature updates, and the impact often turns out worse in practice than it first looks. His specific critique is that user profile versions keep changing, even between Windows 10 builds, so the 'one OS' promise does not hold for the thing that actually matters to admins and users. He calls it 'a tricky problem' and pointedly notes 'helaas is Windows 10 niet het One OS to rule them all gebleken, zoals eerder door Microsoft werd beweerd.' This is an example of him calling out vendor marketing claims against operational reality, naturally landing on the Liquidware fix.
