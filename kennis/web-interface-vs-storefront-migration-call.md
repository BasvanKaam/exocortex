# Keep Web Interface when migrating, choose StoreFront when greenfield (April 2013)

Despite preferring StoreFront elsewhere, Bas gives nuanced migration advice: "The general recommendation is to keep using Web Interface when migrating Farms and to go with StoreFront if you can build it from the ground up." His caveat is concrete: complex setups using Smartcard or Token authentication were not yet natively supported in StoreFront (possible, but configured differently). His pragmatic line: Web Interface is EOL/replaced by 2015, StoreFront will eventually have it all, "so why not wait a bit and make life easier?!" A good example of his migrate-or-not reasoning: weigh the feature gap against the timeline.

*Bron: blogpost 'End of Life... to Migrate or not to Migrate?' (2013-04-28), basvankaam.com.*
