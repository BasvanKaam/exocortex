# Obvious cloud trends (multi-cloud, edge, zero trust, serverless, green)

Bas lists the "voor de hand liggend" (obvious, unsurprising) cloud trends:

- **Multi-cloud and hybrid cloud** — companies avoid dependence on a single provider; more flexibility, better cost control, no vendor lock-in.
- **AI and cloud integration** — AI/ML becoming standard in cloud platforms and software (automated analysis, predictive models, smart automation).
- **Edge computing** — processing data at the source instead of a datacenter/cloud, reducing latency and enabling real-time processing.
- **Cloud security and Zero Trust** — every access attempt continuously checked; encryption, MFA and advanced threat detection becoming the norm.
- **Serverless computing** — developers write code, the cloud handles the rest; lowers cost, ideal for dynamic workloads.
- **Sustainability / green cloud** — energy-efficient datacenters, renewable energy, better cooling, CO₂-neutral solutions.
- **Cloud-native applications** — microservices and containers for scalability; Kubernetes remains key.
- **Quantum computing in the cloud** — AWS, Google, Microsoft experimenting; early stage, for complex calculations like medical simulations and cryptography.
- **Regulation and compliance** — stricter data/privacy laws (GDPR) and the rise of 'sovereign cloud'.
- **Cloud-based collaboration tools** — remote work persists; Teams, Google Workspace getting smarter with AI.
