# Iterate, don't run big-bang projects

Bas's recurring stance across the Enterprise journey: extend and improve an environment through small iterative changes rather than major projects. Onboard new departments and customers by reusing the same Foundations framework instead of rebuilding each time, and "make incremental changes and monitor, don't set and forget" when tuning auto-scale and sizing. The position is that durable optimization is a continuous discipline, not a one-off implementation.
