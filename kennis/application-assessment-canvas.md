# Application Assessment Canvas

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

The Application Assessment Canvas is The framework's instrument for standardizing assessment output per bundle of applications. It ensures all vital information about an application is captured and irrelevant information is excluded.

Its purpose is to combat Analysis Paralysis: the difference between a 'good enough' and a 'perfect' assessment can be weeks or months of work, and getting locked down in the analysis phase is a real risk for any assessment team. Standardizing the deliverables per bundle is how you know when good is good enough.
