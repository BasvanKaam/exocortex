# Reference Architecture Maintenance

> Referentie uit het Weolcan Cloud Governance Framework (WCGF). Niet Bas zijn eigen IP, hier bewaard als naslag.

In the Cloud Governance Framework, a Reference Architecture is the technical guide that self-organizing teams use. Because cloud teams innovate fast and generate many architecture requests, the architecture has to be actively maintained to stay suitable.

The maintenance trigger is the dispensation request. A single dispensation request triggers maintenance of a reference architecture; multiple requests should trigger the responsible role(s) to review the reference architecture and verify its sustained suitability.

The aim of the process is to reduce technical and governance debt. Reference architectures are decomposed into lightweight architecture patterns: chunks of design matched to a specific use case, tied to practical items such as configuration blueprints, deployment scripts, or validated security baselines for services.
