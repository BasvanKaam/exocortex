# Bas's 2018 reframe: true VDI from the cloud and Microsoft licensing

Bas's original 2016 position was that 'true' VDI (or DaaS) from the cloud, meaning VMs with a desktop OS assigned one-to-one, was hard to achieve, mainly because of Microsoft's licensing restrictions. Most DaaS solutions were therefore RDSH/XenApp in the back-end, sharing a 'desktop' among multiple users.

In his 2018 update he explicitly corrects himself: this is no longer true. DaaS today can be Windows 10 as well, pointing to the Windows 10 Microsoft CSP licensing model. This is a good example of Bas annotating his own book with later corrections rather than rewriting history.

## Bron-citaten (NL, verbatim)

> 2018 update: this is no longer true
>
> 2018 update: today this van be Windows 10 as well. Think about the Windows 10 Microsoft CSP licensing model.
