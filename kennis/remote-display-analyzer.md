# Remote Display Analyzer: a community HDX codec tool

The Remote Display Analyzer is a community tool developed by Bram Wolfs and Barry Schiffer (www.rdanalyzer.com, @rdanalyzer). It shows which HDX codec is being used, with related information, in just two mouse clicks (one double-click) - no command prompts, WMI queries, HDX Monitor or Director needed. Its standout feature: it can change display settings on the fly and LIVE switch between available codecs (Framehawk included) without logging out, reconfiguring or rebooting. Bas calls this an industry first, noting even Citrix hadn't produced something similar. Real-time statistics can be viewed with a normal user account (no admin needed). It can also switch between encoders and between DCR and ThinWire.
