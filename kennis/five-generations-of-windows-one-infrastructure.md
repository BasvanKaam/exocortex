# Delivering five Windows generations from one infrastructure

How it worked then (2014): Citrix pitched XenDesktop 7.5 as able to host five generations of Windows desktops and applications from one central infrastructure: Windows Server 2008 and 2012, plus Windows XP, 7 and 8. The point was delivering apps and desktops from multiple Windows OSes without building separate IMA/FMA infrastructures, reducing compatibility issues. A big change versus XenApp 6.5 and earlier, but nothing new from the XenDesktop 7.x line itself.
