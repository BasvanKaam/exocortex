# NVP Community Award Program: Code of Conduct Design

The Nerdio Valued Professional (NVP) program is an award program built to recognize and celebrate exceptional professionals and community engagement around Desktop as a Service and cloud PC technologies. Its governance model is a reusable template for running a vendor community-advocate program.

The Code of Conduct anchors the program on a set of named principles, each a practical lever for keeping a community program credible:

- Professionalism and respect: participants interact with respect, empathy, and consideration toward fellow members, judges, organizers, and stakeholders regardless of background, role, or experience.
- Integrity and honesty: no deception, plagiarism, or misrepresentation of work or achievements.
- Collaboration and sharing: a collaborative environment where members share knowledge, insights, and experiences and stay open to constructive feedback.
- Inclusivity and diversity: embrace diversity across gender, ethnicity, age, and background; discriminatory behavior or language is not tolerated.
- Confidentiality: respect sensitive information as outlined in the program NDA; seek permission before sharing anything beyond program boundaries.
- Professional development: members use the program as an opportunity to keep improving skills, knowledge, and contributions to the IT community.
- Compliance with laws and regulations and industry standards.
- Constructive feedback, given and received considerately.
- Upholding the reputation of the program: each member's behavior reflects on the program.

Enforcement: violations can range from warnings to disqualification, scaled to severity. Organizers reserve the right to act to protect the integrity and fairness of the program. The Code of Conduct is bound to the program NDA: signing the NVP NDA constitutes agreement to the Code of Conduct.

The design pattern worth reusing: pair a values-based Code of Conduct with a signed NDA so that one signature carries both the behavioral commitment and the confidentiality commitment, and tie consequences explicitly to the program's reputation.
