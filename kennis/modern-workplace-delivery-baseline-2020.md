# Baseline Criteria for Modern App and Desktop Delivery (anno 2020)

To compare app/desktop delivery solutions like-for-like ('appels met appels'), Bas set a baseline for the modern digital workplace anno 2020. The yardstick a solution should meet to be in scope:

- Publishing of applications and desktops.
- Up to thousands of users / workspaces.
- Based on the MS RDP protocol.
- Supports single and multi-user (VDI / RDSH).
- HTML5-based browser support.
- 'Oud wordt nieuw': SaaS-ifying legacy.
- Cloud-native is a plus.
- Average-to-intensive usage, may be a bit more.
- SSO, MFA, conditional access.
- Image management.
- On-premises and cloud.
- Gateway as a service.
- High degree of automation.
- Monitoring and reporting capabilities.

A shared prerequisite across all these solutions: they all do 'something' with users, apps and data, with or without a (virtual) desktop, so a user-profile solution is recommended. For Microsoft estates (Office/Microsoft 365, RDSH/RDP multi-user, etc.) the profile choice is now easy: the FSLogix portfolio.
