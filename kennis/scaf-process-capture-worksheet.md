# SCAF process-capture worksheet structure

A fixed-format worksheet from the Cloud Masterclass SCAF supporting documents, used to formally document a single process during cloud adoption. The template forces a consistent layout so processes are navigable and ownable rather than tribal knowledge.

The template captures, in order:
- A version table: version, date, description, name (change history).
- Process name, goal, and owner.
- Roles and responsibilities: title/function paired with name and a short responsibility description (RACI-style allocation).
- Numbered process steps (Step 1, 2, 3, ...) each with an activity description.
- An overview slot for a screenshot of, or link to, the separate flowchart document.
- Four boundary fields: Input (what starts the process), Grenzen/boundaries (where it begins and ends), Output (the end result), and Controle/control (whether and how/when a check occurs).

The "Bij boek" variant (SCAF - Proces Vastlegging) is identical content. Specific to the training as a fill-in artifact; the SCAF framework itself is already distilled from the book.
