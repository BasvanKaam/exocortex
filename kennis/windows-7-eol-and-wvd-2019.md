# Windows 7 End of Support and the Windows Virtual Desktop (2019)

Time-bound specifics from early 2019.

Microsoft ends support for Windows 7 on 14 January 2020. End of support means no more security updates and patches, unless an organization pays for Extended Security Updates.

Microsoft softened its Windows 10 servicing policy: from late 2018 you may keep using a chosen Windows 10 version for 18 months from its official launch date.

The Windows Virtual Desktop (WVD), then a new and not-yet-launched Microsoft service expected later that quarter, is presented as a possible solution. Notable points as known at the time: it bundles 3 years of free extended support for Windows 7; it is licensed via Microsoft 365; it offers a multi-user variant where multiple users work simultaneously on a single Windows 10 machine (a concept long known from Windows Server). At launch WVD was expected to be Azure-only, with rumors of a later on-premises (hybrid) variant.

Use cases he names for keeping Windows 7 longer: an application set dependent on Windows 7, lack of time or financial resources to move to Windows 10, or being mid hybrid-cloud transition.
