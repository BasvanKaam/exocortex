# Why the book uses a fictional case

Not every reader has a concrete use-case to apply the assignments to, so Bas includes a fictional case to let you practise the book's knowledge and methods in a safe, controlled environment. "Oefening baart kunst" (practice makes perfect). By working with the case you become familiar step by step with the processes, challenges and decisions of a cloud migration and onboarding.

He stresses that not every detail or possible step is fully worked out; that would be impractical and barely achievable. In practice steps are often skipped or done in a different order depending on the situation, organisation or goals. The case is meant to give direction, so not every chapter has an assignment. For example, writing a security policy he considers too far-reaching for a book like this, so chapter 10 deliberately has no assignment.

Key learning stance: while doing the assignments there are no wrong answers or outcomes; what matters is that you get going and learn along the way. He encourages using outside sources (Google, GPT, forums, Microsoft Learn) to go deeper, and sees the book as a guide for the first steps, since "de reis naar de Cloud is nooit lineair."
