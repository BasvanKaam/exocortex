# Evolution of Cloud architectures (timesharing to hybrid)

Bas's high-level overview of the phases in Cloud architecture evolution:

- 1960-1980 Time Sharing: lets multiple users share compute on one mainframe - the first step toward shared IT resources.
- 1980-1990 Client-server: users access centralised resources on a server over a network.
- 1990-2000 Thick Computing: many applications installed directly on powerful desktop computers rather than servers.
- 2000 SaaS and Grids: Cloud computing begins as SaaS services (e.g. Salesforce) and grid computing, with compute and storage offered as a service over the internet.
- 2005-2018 Cloud computing: the Cloud as we know it, with resources made available via platforms like AWS and Azure.
- 2020+ Hybrid Cloud: trend toward keeping IT partly on-premises and partly in the Cloud to combine the best of both worlds.
