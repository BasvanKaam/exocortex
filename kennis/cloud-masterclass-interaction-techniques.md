# Cloud Masterclass interaction toolkit for engagement

Bas keeps the Cloud Masterclass interactive with a recurring set of engagement moves he weaves through the material:

- Add your own insight to a topic (the trainer's perspective on each point).
- Tell a personal story or practical real-world example.
- Ask the room questions.
- Drop in a multiple-choice question on screen.
- Run a live demo of something, for example a website.
- Ask the room for input and capture it on a whiteboard.
- Surface the three biggest cloud challenges (a recurring group prompt).
- Work a case: solve a real problem together.

This is delivery craft specific to how he facilitates the training, not framework content.
