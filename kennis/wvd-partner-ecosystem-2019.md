# WVD technology partner ecosystem reached 13 partners (2019)

When Windows Virtual Desktop (WVD, now Azure Virtual Desktop) moved past tech preview in 2019, Microsoft officially announced an expanding technology partner ecosystem; Bas's v2.0 cheat sheet captured 13 partners (up from his v1.0 during tech preview). Partners referenced in tags include Citrix, VMware, Nerdio, Workspot, ControlUp, Lakeside, Liquidware, LoginVSI, CloudJumper, DeviceTrust, PolicyPak, PrinterLogic, ThinPrint. Source was the then-current Microsoft Docs partner page. How it worked then: a single-A4 overview was a useful way to track the young WVD partner landscape. Note: this is one of the earliest appearances of Nerdio in Bas's posts.
