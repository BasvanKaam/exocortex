# AVD / Windows 365 Discovery Questions (Bas's Talking Points)

Bas's set of opening discovery questions for an AVD / Windows 365 conversation. The structure is the reusable part: each question maps to a Nerdio capability and surfaces a pain the prospect may not have named yet. The pattern is 'how are you *currently* doing X', which gets them describing their own gaps.

**Management & resilience**
- How are you currently managing your AVD host pools?
- When there is an Azure outage, how do you keep everything running without your users noticing?
- Are you able to manage Azure Virtual Desktop and Windows 365 Cloud PC side by side?

**Application & image lifecycle**
- How do you handle your application landscape: deployment, updating, securing, maintaining?
- How do you automate image updates and repeat them hourly / daily / weekly / monthly / after Patch Tuesday?

**Cost & reporting**
- How much are you currently saving using Azure Virtual Desktop?
- How are you reporting on current AVD costs and breaking them down per user?
- How are you cost-estimating new use cases for Azure Virtual Desktop?

Reusable as a discovery framework: lead with the customer's current state across the three axes (run/resilience, lifecycle, cost), and let the gaps justify the tooling.
