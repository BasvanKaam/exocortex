# Microsoft's 'one Windows 10 to rule them all' promise was false

In December 2017, ~2.5 years after Windows 10 shipped, Bas pushes back on Microsoft's marketing claim that Windows 10 would be a single enduring OS. His stance: 'Yes, Windows 10 will stay Windows 10' in name, but technically things change build to build, and the profile-version incompatibilities prove the promise was hollow ('nothing could be further from the truth'). He frames the steady stream of Windows 10 updates to come as a recurring migration headache, not a one-time event, unless you abstract the profile. The fix he advocates is a universal, native-format Windows profile that works across all Windows desktop and server versions: 'configure once, migrate many', which Liquidware calls a Profile Bridge.
