# Cloud Masterclass agenda and module timings

Draft agenda for the Cloud Masterclass (deck co-developed with Marcel Kornegoor, framed around "the Cloud anno 2020"). The day is broken into modules with indicative timings (excluding breaks, dependent on questions and interaction):

- Principles and technologies / the new business reality (45 min)
- Cloud economics (1 h)
- Architectures and services (45 min)
- Security (1 h)
- Data in the Cloud (1 h)
- Exit strategy (1.5 h)
- Community and practical tips (1 h)
- Future and trends (1.5 h)
- Roadmap planning and Cloud adoption (1 h)

The deck opens with framing quotes used to set the tone, e.g. "These and future generations don't know what it means to be offline" (Bas van Kaam) and the ironic "Go to the Cloud they said, it will be cheaper they said. - Everyone." Dated because it is anchored to a 2020 snapshot of the cloud landscape and module split.
