# Liquidware suite: ProfileUnity, FlexApp, Stratusphere UX (2018)

How it fit together in 2018. Liquidware's Essentials Bundle combined three products managed alongside each other: ProfileUnity (user environment management with hundreds of context-aware filters for per-user / per-group / per-OU configuration, plus built-in profile migration that transforms legacy profiles to newer OS versions including Windows 10, and direct cloud-storage integration with AWS, Azure, Google so you don't need SMB file shares), FlexApp (application layering, managed from the same console), and Stratusphere UX (user experience and infrastructure monitoring). Bas positions the bundle as a fraction of the cost of Citrix/VMware Platinum editions with no vendor lock-in. Product specifics are dated; the architectural pattern (UEM + app layering + UX monitoring as a single layer above the platform) endures.
