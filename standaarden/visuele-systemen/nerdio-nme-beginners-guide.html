What is Nerdio Manager?

Nerdio Manager for Enterprise (NME) is a deployment, management, and Auto-scaling platform for Azure Virtual Desktop (AVD) and Windows 365 Cloud PC.

IT teams and system integrators use it to run large desktop estates from a single console. It connects to an existing environment or configures a new one.

It adds value on top of Microsoft. It does not replace it.

02

Why organizations use it

  • Cut Azure cost by scaling hosts up for demand and off when idle.
  • One console for AVD, Windows 365, and Intune across the estate.
  • Automate images, patching, and app delivery instead of scripting by hand.
  • Stay in control: NME runs in your own Azure tenant.
  • Delegate safely with granular role-based access control (RBAC).

07

Auto-scale

  • Grows a host pool for demand, shrinks it when idle.
  • Triggers: CPU, RAM, active sessions, available sessions.
  • Scale out on any trigger, scale in only when all clear.
  • Works on dynamic and personal host pools.
  • Auto-heal repairs broken session hosts.
08

Image management

  • One golden image, versioned and staged.
  • Automate patching around Patch Tuesday.
  • Test on a staging host pool, then activate.
  • Re-image hosts to the new version on a schedule.
  • Marketplace, custom, and Azure Compute Gallery images.
09

FSLogix profiles

  • Configures and manages FSLogix profile containers.
  • Automates the share: storage, permissions, domain join.
  • Multiple profile configurations per host pool.
  • Delete, archive, and restore profiles from User Sessions.
  • Storage on Azure Files or Azure NetApp Files.
10

Security & access control

  • Sign in with Entra ID; console supports multifactor authentication (MFA) and Conditional Access.
  • Granular RBAC: AVD Admin, Desktop Admin, Help Desk, Reviewer, End User, plus custom roles.
  • Encrypted in transit and at rest; Veracode verified.
  • Not locked down by default: run the hardening runbook for private endpoints.
11

Monitoring & insights

  • Insights for AVD, Windows 365, Intune, and executives.
  • Real-Time Insights: live health and session performance.
  • Links Azure Log Analytics workspaces.
  • Daily cost dashboards, broken down by category.
  • Manage Intune endpoints with compliance status.
12

Cost optimization

  • Auto-scale is the biggest lever: pay for hosts only when used.
  • Storage Auto-scale right-sizes Azure Files Premium.
  • User cost attribution splits total spend per user.
  • Modeler estimates per-user cost, optimized versus not.
  • Pair Auto-scale with Reserved Instances for steady load.
13

Licensing

  • Bought and billed through the Azure Marketplace.
  • Two editions: Core and Premium.
  • Consumption-based, per monthly active user.
  • Billed once a month at the highest entitlement used: AVD, then Windows 365, then endpoint management.
  • $1,000 monthly minimum. 30-day free trial.
  • You license Microsoft first (for example, Microsoft 365 E3 or E5).
